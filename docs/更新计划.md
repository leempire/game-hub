### 功能增强

#### P1（核心链路）

- ✅ **主页重做信息架构**（v1.18.1 已完成）：顶部「和朋友开一局」主 CTA（创建 / 输入房间号 / 浏览房间），
  下方「最近玩过」横向列表 + 分类筛选 chips + 搜索。
  验收：390×844 首屏同时看到主 CTA、最近玩过、至少 4 个游戏；13 张卡不再需要滚 2 屏以上。
- ✅ **房间卡补齐信息与可加入性**（v1.18.1 已完成）：房主、玩家昵称、已打局数、玩法摘要、`已满 / 仅重连` 角标；
  加入中单卡 spinner 防重复点击。
  验收：列表里能预判能否加入，不再点进去才被拒。
- **统一对局外壳 `GameShell`**：顶栏（游戏名 / 房间号 / 帮助 / 连接状态）、
  玩家条（双方头像、昵称、执子色、当前回合高亮）、底部行动区、统一结算卡。
  验收：13 个对局屏复用同一套外壳；1v1 六屏任何时候都能看到对手是谁；结算含
  「返回房间 / 房主再来一局 / 查看战绩」。
- **人机难度统一**：除海战棋外的 9 个 AI 游戏补 easy / normal / hard。
  `room_manager.add_bot` 的 `p["ai_difficulty"]`、`ws._bot_difficulty`、房间页难度芯片
  都已存在，只差各 AI 入口接受 `difficulty` 并映射到时间预算/候选宽度/降智概率。
  验收：难度可在加人机前选择并显示在玩家行；三档强度用现有 bench/对局台量过，
  不出现「选了但没生效」。
- ✅ **我的页战绩统计**（v1.18.1 已完成）：总场次、胜率、当前连胜、最常玩的 3 个游戏、最近 7 天对局。
  验收：数据来自 `game_records` 聚合接口（不在客户端拉全量）；空账号有引导态。
- ✅ **棋类逐步回放**（v1.18.1 已完成）：五子棋 / 翻转棋 / 点格棋 / 四子棋的引擎里已有 `moves`
  （军棋连全量真相都有），但 `database._build_snapshot` 没存。补进快照，
  `HistoryScreen` 加一个最小步进器。
  验收：四款棋类能按手前后翻；不新增请求（复用现有快照）；暗棋终局后可「显示真相」。

#### P2（留存与社交）

- **每日挑战**：2048 / 俄罗斯方块 / 扫雷每天一个固定种子，全服同一盘，完成即上榜。
  验收：同一天所有客户端牌序/雷盘一致；显示「今日已完成 / 连续 N 天」。
- **各游戏排行榜**：胜场、最佳分数、最快通关等，人机局不计入。
  验收：榜单分游戏、可分时间窗；并列有稳定排序。
- **战局数据底座**：新增 `game_participants(record_id, user_id, result, rank, metrics_json)`
  与索引，保存战绩时一并写入，从现有 `game_records` 回填。
  验收：统计/排行榜/成就/连胜都读它，不再用 `players_json LIKE` 扫全表。
- **新手引导**：深空休眠、军棋、海战棋、UNO 四款复杂游戏做首次进入的分步提示 +
  「打一局人机练习」入口；标记存 AsyncStorage。
  验收：每款最多 3 步、可跳过；练习局不影响战绩。
- **回放分享**：战绩详情生成分享链接，复用现有快照渲染。
  验收：链接打开可直接看最终局面与关键信息；未登录可看只读回放。
- **社交页落地或隐藏**：二选一——先隐藏 Tab；或放真实内容（在线人数、最近一起玩的人、
  排行榜入口），删除假轮播点。验收：底部不再有整页「正在建设中」。

**bug 修复**
- ✅ **对局中点击返回想强制退出时没反应、返回后闪一下仍然留在房间** ——
  出在深空休眠，而且是**两个缺陷叠在一起**：
  1. `Stasis` 不在 `backGuard` 的 `PROTECTED_SCREENS` 里 → 浏览器返回压根不弹确认框，
     只是导航回房间页，而房间页又因为「房间在游戏中且自己仍在局中」把人弹回对局页
     （看到的就是「闪一下」）；
  2. `stasis.surrender` 原来要求 `phase == "playing"` → **跑动阶段**（开局那 30 秒，
     玩家最想退出的时段）点退出时 REST `/leave` 抛 `ValueError` 变成 500，
     而 **500 响应不带 CORS 头、浏览器把它报成 CORS 错误**，客户端静默吞掉、
     人没被淘汰 → 照样弹回去。
  - **回归网**：`visual_audit.py` 新增静态对账 `audit_back_wiring` ——
    拿 `navigation.tsx` 的路由表逐个核对「每个对局屏都在 `PROTECTED_SCREENS` 里、
    都调了 `onConfirmLeave`」。这类漏接线**不会有任何报错**（TS 绿、跑起来也不崩），
    只会在真机上表现为「点了没反应」，所以用静态扫描兜底，新增对局屏时会直接报红。
