# 公共体验与数据产品调研

2026-11-04，服务于本轮分层实施。各游戏规则调研仍归档到对应游戏目录。

## 组件与移动端

- [React Native 无障碍](https://reactnative.dev/docs/accessibility)：操作提供语义与可见状态；回合不能只用颜色表示。采纳昵称、身份文字、当前行动标记与边框共同显示。
- [React 状态保留](https://react.dev/learn/preserving-and-resetting-state)：状态随组件树位置变化。采纳受控外壳，只抽展示，不把各游戏的 Socket、预测、手势与离开确认挪进外壳，避免重挂载丢状态。
- [Expo SDK 57](https://docs.expo.dev/versions/v57.0.0/)：与 package.json 一致；沿用现有 React Navigation 与 RN 控件，不新增原生依赖。
- 交叉参考仓库《移动端体验设计方法论》的触控尺寸、状态可见性与渐进披露：统一操作至少 44px；长结算可滚动；合作纸牌横屏仍保留自身交互。

不采纳：强迫十五款游戏统一棋盘布局、改变服务端权威规则、无限循环结算动画。

## 导航与分享

- [React Navigation 深链配置](https://reactnavigation.org/docs/configuring-links/) 与[认证流程](https://reactnavigation.org/docs/auth-flow/)：公开只读回放必须在未登录的导航树中可访问；私人房间仍走原认证流程。
- [FastAPI 安全依赖](https://fastapi.tiangolo.com/tutorial/security/first-steps/)：生成分享需要鉴权并检查参与者；读取分享端点单独公开，采用不可猜测的分享令牌，显式裁剪输出。

采纳：复用已有终局快照展示，分享由参与者主动生成；支持撤销。[Expo Clipboard 57](https://docs.expo.dev/versions/v57.0.0/sdk/clipboard/) 提醒 WebKit 异步剪贴板限制，因此先生成可选择的链接，再让用户单独点击复制，失败可手动长按复制。拒绝直接用战绩自增 ID 作为匿名读取凭证、公开进行中的手牌/布阵，以及在匿名接口返回用户安全字段。

## 每日挑战与榜单

- [SQLite 窗口函数](https://www.sqlite.org/windowfunctions.html)与[索引](https://www.sqlite.org/queryplanner.html)：参与者索引作为查询底座，先按游戏/时间窗/练习及人机标记过滤，再聚合；并列显示相同名次，附稳定用户 ID 排序。
- 中文检索观察到[PLAYUS 的周期榜单](https://www.playus.io/zh-Hans/rankings)按今日/周/月/历史区分成绩口径。本项目采纳明确时间窗与分游戏指标，不引入匹配、排位积分或付费奖励。

实现取舍：每日日期统一 UTC；种子由日期与游戏确定，不接受客户端上报分数或完成状态；扫雷每日挑战固定首击位置，避免相同种子因首击安全区不同而改变雷盘；普通房间的既有每日房规保持兼容。重复尝试与练习的成绩隔离规则须随接口与界面明示。
