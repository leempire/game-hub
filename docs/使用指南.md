# GameHub 使用指南

**面向**: 玩家、房主、管理员
**更新时间**: 2026-10-11（v1.8.0：新增俄罗斯方块对战（第 10 个游戏）；v1.7.2 起扫雷格子放大到 44px + 双向滑动、生命值按难度 1/2/3，五子棋落子二次确认，四个棋类统一「最近一步」高亮）

---

## 概述

GameHub 是一个手机小游戏平台。手机浏览器打开本机部署的 Web 地址（`<服务器地址>:50540`）即可玩（无需安装），
也可以下载安卓 APP 获得原生体验。当前开放 14 个游戏：**五子棋**、**中国象棋**、**重力四子棋**、**翻转棋**、**海战棋**、**点格棋**、**军棋（明棋 / 暗棋）**（以上 2 人对战）、**扫雷（1-4 人同盘竞速）**、**飞行棋（2-4 人派对）**、**2048 竞速（1-4 人各自独立盘）**、**俄罗斯方块对战（1-4 人各自独立盘）**、**UNO 卡牌（2-4 人回合制）**、**深空休眠（2-6 人实时合作塔防）**、**蜘蛛纸牌（单人接龙）**。
平台功能：房间制联机（断线重连）、**人机对战**、**历史战绩**、**游戏规则帮助**（大厅/房间/对局中随时可查）。

「游戏」Tab 里这些游戏按**玩法形态**分五类排（单人休闲 / 棋类对战 / 多人桌游 / 各玩各的 / 合作），
每类下面挂几个游戏、各带一句「这游戏是什么」的说明，找起来比一长条列表快得多。

## 单人蜘蛛纸牌

在“单人休闲”中点蜘蛛纸牌，再点“开始 / 继续牌局”。单花色随机发牌，整理八组 K 到 A 即通关。
点选连续明牌组，再点标有“可放”的目标列；手机可左右查看十列、上下查看长牌列。
每次发牌给十列各补一张，有空列时须先填满。支持最近 200 步撤销和合法移动提示。
操作自动保存到账号，离线不会判负；点“保存并返回”后，下次从同一入口续玩。
“新牌局”确认后会结束当前局并重新发牌。随机牌局不保证每局可解。

## 一、注册与登录

1. 打开 Web 版或 APP，进入登录页
2. 切到「注册」：用户名 3-20 位字母数字下划线，密码 6-32 位，注册成功自动登录
3. 登录状态会记住（关浏览器/关 APP 后再开不用重登）
4. 「我的」页可改昵称、改密码、退出登录

## 二、创建/加入五子棋房间

**房主**：
1. 「房间」Tab → 右上「创建」→ 填房间名（可选）、密码（可选，留空为公开房）
2. 进入房间页，把 **6 位房间号** 告诉朋友。也可以直接复制浏览器地址栏里的
   `/room/<房间号>` 链接发给对方：打开链接后登录/注册，会自动回到这个房间
   （密码房仍需输入密码）
3. 等对方加入并显示「已准备」后，点「开始游戏」（房主执黑先手）

**玩家**：
1. 「房间」Tab → 列表里直接点公开房加入；或点「加入」输入房间号（有密码的房要填密码）
2. 进入房间点「准 备」
3. 房主开始后自动进入棋盘页（加入者执白）

**对局中**：
- 轮到你时点棋盘交叉点落子，五连即胜
- 「认输」立即判负；对局结束点「返回房间」回大厅，房主可直接「开始游戏」续开新一局

**换位置（等待大厅里）**：名单里每个人右边都有一枚「换位」按钮，点它就向对方发出换位请求，
按钮会变成「等待同意」直到对方答复（对方没答之前再点一次只会重发同一条请求）。
**对方是人机会直接同意**；是真人则他那边会弹出确认框，他点「同意换位」之后你俩的位置才对调
（**谁也不能单方面挪走别人的座位**）。座位决定谁先手 / 谁先出牌，所以**只有开局前能换**——
一开局座位就锁死了，想换得等这一局打完回到大厅。

**没有朋友在线？** 房主点「添加人机」即可与 AI 对战（见「九、人机对战」）。

**操作小贴士**：轻点交叉点会先放下一枚**半透明预览子**，**再点同一位置**才真正落子（点别处可改位置、点已有棋子可撤销）——这是为了防止一步误触直接输掉。按住棋盘会浮出**放大镜**，拖动可调整瞄准的交叉点后松手，落点同样进入「待确认」；**双指捏合可缩放棋盘**（1×~2.5×），放大后单指拖动可平移，右下角「复位 1×」回到原状。胜利的五连会深红圆环高亮，**最近一手**棋子上有黄点标记（翻转棋/点格棋/中国象棋同样会标出最近一步），轮到你时顶部提示脉冲闪烁几次后常亮（APP 端伴随轻震）。

## 三、扫雷同盘竞速（1-4人）

1. 「游戏」Tab 点扫雷卡片 → 创建房间；或在「房间」Tab 创建时选游戏类型
2. **进房之后由房主选难度**（初级 9×9/10雷、中级 16×16/40雷、高级 16×30/99雷）——难度与军棋的玩法、深空休眠的地图一样是**房间里的设置**，改完全房可见；开局之后改不了
3. 朋友加入后各自点「准 备」，房主点「开始游戏」（**1 人房可直接开始当单机玩**）
4. 玩法：所有人操作**同一张盘面**、同时进行（没有回合）比谁挖得准、挖得多；**每人按难度有 1/2/3 条命**（初级 1 / 中级 2 / 高级 3），踩雷扣一条命、**命扣完才淘汰**（观战到本局结束），其余人继续。玩家状态条上每人显示 `♥ 剩余/总数`，只剩一条命时心形变空心、数字转琥珀色
5. 个人统计：你翻开的每个安全格、正确标出的每枚雷都计入自己名下（错标不计数、乱插旗无收益）
6. 插旗：**长按格子约 0.4 秒**即可插旗（APP 端有轻震），也可以点「翻开模式」切到插旗模式再点。已插旗的格子在翻开模式下点击无效，切回插旗模式再点一次才能取消（防误触）
7. **快速展开（chording）**：点一个已翻开的数字格，若它周围的旗数与数字相等，其余邻格会一次全部揭开——数字周围已经插好旗时用它一口气推进
8. 第一次翻开必定安全（不会踩雷），放心开第一格
9. **结算与排名**：全员淘汰或全部安全格翻开时结算并公开所有雷。幸存者排名靠前，组内先比正确标雷数、再比翻开格数；淘汰者垫底。结算面板逐人显示 存活/淘汰、标雷✓、错标、翻格 数

## 四、翻转棋（奥赛罗，2人对战）

1. 「游戏」Tab 点翻转棋卡片创建房间，或「房间」Tab 创建时选游戏类型；朋友加入后准备、房主开始
2. 黑先；落子必须至少在一个方向**夹住**对方棋子，被夹的棋子全部翻面
3. 自己的回合会有**空心圆环**提示所有合法落子位（圆环脉冲几下后常亮）；点其他位置无效。棋盘带 A-H / 1-8 坐标标注，方便复盘时说位置
4. 无合法着法时自动跳过回合（Toast 提示"自动跳过"）；双方都无着法或棋盘满即终局，**子多者胜**，可平局

## 五、海战棋（2人对战）

1. 「游戏」Tab 点海战棋卡片创建房间，或「房间」Tab 创建时选游戏类型；朋友加入后准备、房主开始。**房主可在等待大厅里点「玩法设置」选棋盘尺寸**（与扫雷难度、军棋玩法一样是房间里的设置，改完全房可见，开局后改不了）：**闪电战 6×6**（4 艘小船，两三分钟一局）/ **标准 10×10**（经典 5 艘）/ **大战场 12×12**（6 艘，船更难找）
2. **布阵阶段**：在自己的海域摆放军舰（标准档是 10×10 摆 5 艘，占 5/4/3/3/2 格；6×6 是 4 艘、12×12 是 6 艘，不可重叠出界）。默认已随机布好，可点「重新布阵」换一套；也可手动摆：选中船 → 点格子放置 → 「旋转」切换横竖，点已放的船可收回；**长按舰船拖动**可直接拖到目标位置（拖动时合法位置实线白边、非法位置虚线琥珀边）。摆好点「完成布阵」，双方都完成即开战（布阵互相保密）
3. **对战阶段**：点击对方海域开炮——**落空**（画圈）/**命中**（画叉）/**击沉**（整块沉没，广播提示）；**命中或击沉后回合保留**，可以接着再打（只有先手方的第一发不触发，算是对后手的补偿）；己方被炮击的位置同步显示。棋盘一次只显示一块，用顶部「我的海域 / 敌方海域」切换（格子因此更大、更好点）
4. **特殊武器（每件每局一次）**：布阵时把 **雷达 / 齐射 / 空袭** 分别挂到三条**不同的**舰船上（布阵页「特殊武器」面板，点芯片换携带舰）。**携带它的舰被击沉，武器就失效**；挂靠关系**对手可见**，所以「找出并击沉对手的武器舰」是正经打法。雷达只报选定格周围 3×3「有没有舰」（不报位置），齐射一次打你点名的 3 格，空袭打选定格周围 3×3。**用武器就是本回合的全部行动**——用完换手，不触发上面的续射
5. 先击沉对方**全部军舰**获胜（标准的 5 艘 / 闪电战 4 艘 / 大战场 6 艘）；可「认输」。结束后点「返回房间」，房主点「开始游戏」即可续开下一局（重新布阵）
6. 小技巧：**武器目标只能在「敌方海域」上选**（点武器芯片会自动切到那一侧；切回「我的海域」会取消瞄准）；雷达先探出「这片海有舰」再决定往哪儿打，比盲打好；对手的武器舰名字是公开的，优先打沉它能直接废掉一件武器

## 六、点格棋（Dots and Boxes，2人对战）

1. 「游戏」Tab 点点格棋卡片创建房间，或「房间」Tab 创建时选游戏类型；朋友加入后准备、房主开始（房主执蓝先手）
2. 5×5 点阵（4×4=16 个格子），轮流点击相邻两点之间的位置**画一条边**
3. 画的边恰好封住一个格子的第 4 条边：格子归你（半透明着色）+1 分，并**额外再画一条**（可连锁封格）
   - **封格提示**：轮到你时，「画下去能封住格子」的那条边会用**琥珀色加粗**标出来，顺着画就能连封；提示只在自己回合出现
   - 轮到你时其余未画的边会显示成**细虚线**（可画的边在哪里一眼可见），虚线 ≠ 已画的实线，不会看混
   - 反过来看：如果某条边被对手的提示标着，说明你**不该**画它（画了就是送对手一个格子）
4. 40 条边画完终局，**格子多者胜**，可平局；可「认输」，结束点「返回房间」由房主续开
5. 没有朋友在线可「添加人机」：AI 会抢封格、避免送长链，有一定棋力
6. 小技巧：别画第 3 条边（等于送分）；中盘识别"链"，开长链时留最后两格（双打策略）换控制权

## 七、飞行棋（2-4人派对）

1. 「游戏」Tab 点飞行棋卡片创建房间；**2-4 人**，2 人即可开局（不必满员）；房主可点「添加人机」加 AI，**最多连加 3 个**凑满 4 人局
2. 每人一色 4 架飞机停在基地；轮到你就点「掷骰子」，**掷出 6** 才能起飞一架，且掷 6 后可**再掷一次**
3. 骰子点数由服务器裁定；有可动飞机时点高亮的飞机移动（掷出点数后自动列出可动目标）
4. **同色跳格**：赛道 52 格按蓝→绿→红→黄四色循环着色（每色 13 格），你的起飞点就是自己的颜色。飞机落点若正好**踩在自己颜色的格子**上，会再向前跳到下一个同色格（多走 4 格），只跳一次
5. **虚线捷径**：棋盘上有四条虚线箭头（黄/蓝/绿/红各一条），**一条归一个玩家**。只有你的飞机踩到**自己颜色的那条**虚线起点格，才会**沿虚线飞 12 格**到另一个同色格；若是「跳」到这个虚线格上的，则飞完就停。别人的虚线对你无效——画面上你自己那条的起点是实心圆、其余是空心圆
6. **撞机与迭子**：落在敌机所在格，敌机被打回基地。若落点是自己颜色格且格上已有敌机，则直接撞落、不跳不飞。自己的多架飞机停在同一格叫「迭子」——敌机**不能飞越**（路径被挡住就走不了），若正好落在迭子上则**同归于尽**，双方全部回基地
7. **危险格**：轮到你时，对手 1~6 步内能够到的格子会罩一层淡红并多一圈红环，落在那里下一手就可能被撞回基地。**连掷 3 次 6**：乐极生悲，自己全部飞机回基地并失去回合
8. 终点需**精确到达**，超出步数折返；4 架全部到终点即完成
9. 只剩一人未完成时终局，按完成飞机数**排名结算**；中途「认输」= 弃权（飞机回基地、排名垫底），其他人继续玩

## 八、2048 竞速（1-4 人各自独立盘）

1. 「游戏」Tab 点 2048 卡片创建房间；**1-4 人**，1 人也能开局（就是经典单人刷分），不支持人机
2. **各玩各的，不是轮流**：每人一份自己的棋盘，你随时可以滑，不用等别人
3. **公平**：所有人棋盘使用完全相同的出块序列（同种子），比的就是操作与规划
4. 操作：在自己棋盘上**滑动**（上/下/左/右），或点屏幕下方的**方向按钮**；相同数字碰撞合并翻倍
5. 右上角**实时排行榜**（点胶囊展开）按分数排序，显示每人分数、最大方块、是否已结束；自己那行高亮。嫌挡棋盘可以**拖动**浮层挪位置
6. **结束是逐人的**：合成 2048 即完成，或棋盘卡死即结束。认输/中途退出**只结束你自己**（排名垫底），其他人照常继续
7. 全员结束后按名次结算：**先合成 2048 的排最前**（按达成先后），其余按总分从高到低
8. **这是跑分竞速，不是胜负对抗**：结算时**只有真的合出 2048 才显示「胜利」**，分数最高但没合出来也只是「游戏结束」+ 名次。
   排行榜上显示的是**用户名**（不是「红方/蓝方」——颜色按入座顺序发，不代表身份也不是名次）
9. 结束点「返回房间」由房主续开

## 九、俄罗斯方块对战（1-4 人各自独立盘）

1. 「游戏」Tab 点俄罗斯方块卡片创建房间；**1-4 人**，1 人也能开局（就是经典单人刷分），不支持人机
2. **各玩各的，不是轮流**：每人一份 10×20 的盘，你随时可以操作，不用等别人
3. **公平**：所有人使用完全相同的方块序列（同一个随机种子），比的是摆放而不是运气
4. 操作：屏幕下方**左移 / 旋转 / 下移 / 右移 / 直接落底**五个按钮；也可以直接在棋盘上**左右滑动**移动、**下滑**软降、**上滑**旋转。虚线框是方块将要落到的位置
5. **消行得分**：1/2/3/4 行 = 100/300/500/800 分，再乘以等级（每消 10 行升 1 级，等级越高掉得越快）
6. **攻击行**：一次消 2/3/4 行会给**所有对手**从底部顶上来带空洞的行（消 1 行不攻击）。被顶时整堆方块抬高，方块被顶出天花板就出局——所以既要打得快，也要堆得低
7. 右上角**实时排行榜**（点胶囊展开）按分数排序，显示每人分数、行数与是否已结束
8. **结束是逐人的**：方块顶到天花板（或被攻击行压死）即出局。认输/中途退出**只结束你自己**（排名垫底），其他人照常继续
9. 全员结束后按名次结算：撑到最后的排最前，同批出局按分数从高到低
10. 结束点「返回房间」由房主续开

## 十、UNO 卡牌（2-4 人回合制）

1. 「游戏」Tab 点 UNO 卡片创建房间；**2-4 人**，满 2 人即可开局，房主可加人机凑人
2. **每人只会看到自己的手牌**，对手那一栏只显示「还剩几张」——这是牌类游戏的基本规矩
3. **开打前房主可以在房间里选玩法**（见下），选完全房都能看到；开局之后就改不了了
4. 轮到谁，只有他能出牌或摸牌；不是你的回合时按钮与手牌都是灰的
5. **出牌规则**：颜色相同、或数字/符号相同就能出；黑牌（变色、变色+4）任何时候都能出
6. **罚牌可以叠加**：被 +2 时如果你手里也有 +2，可以再打出去把这笔账转给下家（经典档：+2 只能压 +2，+4 只能压 +4）。一路传下去，最后接不上的人一次摸完累计张数并停一轮——牌桌下方会亮出「待罚 N 张」
7. **摸牌与过牌**：没牌可出点牌堆摸一张；摸到能出的牌可以立刻打出去，也可以点「过牌」。注意**摸过牌这一轮就只能出刚摸到的那张**
8. 手里只剩一张时会出现「喊 UNO」按钮，点一下让全桌都知道
9. **第一个出完手牌的人获胜**，其余人按剩余手牌点数排名（数字牌按面值，功能牌 20 分，黑牌 50 分）
10. 认输/中途退出**只让你出局，牌局继续**；只剩一个人时才算结束。轮到你时若你已掉线，系统会替你摸一张并过牌，不让全桌干等
11. 结束点「返回房间」由房主续开

**玩法档位与房规**（房主在等待大厅里点「玩法设置」打开，双方实时可见）：

房间页上只有一行「玩法设置 · 当前档位 ›」——**点它打开设置面板**，档位与 7 条房规都在里面。
（房主点一下就生效、全房同步；非房主也能打开看当前设置，只是改不了。）

| 档位 | 说明 |
|---|---|
| **经典** | 标准的 UNO：+2 只能叠 +2，第一个出完手牌的人获胜 |
| **热闹** | 抢出 + 7 换手 + 摸到能出为止 + 有牌必出 + 罚牌可越叠越大——牌权频繁易手，节奏最快 |
| **无怜悯** | 换掉整副牌（164 张的狠牌堆）+ 罚牌能叠到 +10 + 摸到能出为止 + 7 换手 / 0 传手 + **手牌涨到 25 张直接出局** |
| **组队** | 2v2：**恰好 4 人**，座位 0/2 一队、1/3 一队（**坐在你对面的是队友**），一队**两人都出完手牌**才算赢。出完手牌不是出局，而是接管队友一半接着打 |
| **自定义** | 下面几行开关随时可改，改到不匹配任何预设时档位就显示成「自定义」 |

可以逐条改的房规：**叠牌**（不叠 / 同型叠加 / 等值或更高）、**摸到能出为止**（没牌可出时一直摸到能打的那张）、**有牌必出**（手里有能打的就必须打，不能靠摸牌拖延）、**抢出**、**7 换手 / 0 传手**、**牌堆**（标准 / 无怜悯）、**25 张淘汰**、**组队**（各自为战 / 2v2）。

**2v2 组队**：选它之后必须凑满 **4 人**才能开始（人数不对时点「开始游戏」会提示「组队模式需要恰好 4 名玩家」）。**坐在你对面的那个人是队友**，他那一格会标一枚「队友」徽章。队友之间照常各看各的牌，互相看不到手牌。

这一档有四条与经典不同的规则：

- **出完手牌不是出局，是从队友手里接管一半**：你把牌打光时，队友把手里**一半**交给你（他 9 张就传你 4 张、自己留 5 张），你拿着这半副接着打。**只有队友手里只剩 1 张**（半手传不出来）时你才真的留在场外——那就等他打完最后一张，你们俩同时空手才算赢。所以真正决定胜负的是**你队友还剩几张**。
- **人在场外也能被拉回来**：队友**只要摸到牌**（被罚、自己摸、颜色轮盘翻出来都算），就立刻分你一半、把你拉回场上。
- **队友能替你喊 UNO**：谁只剩一张，两个人都能喊——按钮上会写「替队友喊」。
- **两张专属黑牌**（各 2 张，牌堆 112 张）：**传给队友**（选色 → 回合直接跳到队友，他接不住就罚你摸 2 张）与**全队罚四**（下家摸 2 停一轮，**他的队友也摸 2**）。

**无怜悯牌堆**多出六种狠牌：**跳过所有人**（别人全被跳过，你再来一轮）、**弃同色**（把手里其余同色牌一口气全丢掉，丢掉的牌不结算效果）、**变色+6**、**变色+10**、**变色反转+4**（先转向，那个方向的下家摸 4 并停一轮）、**颜色轮盘**（由**下家**点名一个颜色，然后从抽牌堆一张张翻到这个颜色为止，翻出来的牌全归他并停一轮）。

**25 张淘汰**开着时，手牌涨到 25 张就直接出局。注意这不是「出完牌的人被淘汰」——出完手牌照常获胜；它是官方的第二种获胜方式：**别人都被淘汰掉、只剩你一个时，你获胜**。所以往别人手上堆罚牌是一箭双雕。

- **抢出**：手里有与牌堆顶**完全相同**（同色同数字）的牌时，不管轮到谁都能立刻打出去，回合从你继续——这张牌会带一枚「抢出」角标，点它就行。同一张牌可能好几个人都有，先点到的抢到；抢输了会提示你。黑牌不能抢出。
- **7 换手 / 0 传手**：打出 **7** 要先选一名玩家，跟他**交换全部手牌**（你把手里的给他、拿他那一手，换给手牌最少的人通常最划算）；打出 **0** 则所有人按当前方向把手牌传给下家。换手之后手里只剩一张的人**要重新喊 UNO**。

## 十一、军棋（陆战棋，2人对战 · 明棋 / 暗棋）

1. 「游戏」Tab 点军棋卡片创建房间；**2 人**，满员开局，房主可加人机
2. **开打前先选玩法**（房主在等待大厅里点「玩法设置」打开）：**明棋**是双方棋子全公开、纯拼算路；**暗棋**只看得到自己的棋子、对方的扣着。选暗棋还能再切一个「阵亡是否公开棋子身份」——关着就是经典暗棋（只告诉你「谁出局」），开着则每次碰子都亮出阵亡的棋子（明棋下这一项不显示，因为它没有意义）
3. 开局先**布阵**：系统给双方各发一套随机阵型，**点两枚棋子交换位置**；另有「随机」重掷，以及一排**经典阵型芯片**（双喜临门 / 午夜风铃 / 飞花逐月 / 飘香一剑 / 三节阵）——点一下整套摆好，不用一枚枚换。摆好点「确认布阵」，**双方都确认**才开始。交换是否合法由服务端判定——军旗必须在大本营、地雷只能放在最后两排、炸弹不能放在第一排，点错了会直接告诉你原因
4. **每方 25 枚**：司令、军长、军旗各 1；师长、旅长、团长、营长、炸弹各 2；连长、排长、工兵、地雷各 3
5. **大小**：司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵。大的吃小的，**同级同归于尽**
6. **特殊棋子**：**炸弹**碰上谁都同归于尽；**地雷**不能动、只有**工兵能挖**（别的子撞上去是自己被吃）；**军旗**不能动、被碰到就输；**司令阵亡**则该方必须亮出军旗位置
7. **走法**：细线（公路）一步；粗线（铁路）直线不限格数、**工兵能在铁路上拐弯**；圆圈是**行营**——里面不会被攻击、但也只能走一步；端线中间两格是**大本营**，进去就出不来了；两处折线是**山界**，过不去
8. 操作：**点自己的棋子 → 再点高亮落点**（两步式，误触可以先撤销）。空位是实心圆点、可吃的敌子是圆环
9. 底部一排是你**还剩哪些棋子、各几枚**——25 枚记不住是常事
10. **胜负**：吃掉对方军旗即胜；把对方能动的子吃光（轮到他一步都走不了）也胜。认输、掉线超时判负，长时间没吃子判和
11. 结束点「返回房间」由房主续开

## 十二、深空休眠（2-6 人实时合作塔防）

1. 「游戏」Tab 点深空休眠卡片创建房间；**2-6 人**，≥2 人即可开局，房主可加人机。**房主可在等待大厅里点「玩法设置」选地图**：标准货舱区（25×30）/ 双人套间（两人共用一道外闸门，逼你们分工）/ 中庭货舱（通道最长、支援距离最远）
2. **开局 30 秒跑动**：用左下角摇杆跑到一间空舱室、走到**休眠舱旁边点「躺下」**（在走廊里、门口都躺不下）。舱室**跟着人走**——走出去就自动让出、走进另一间空房就换过去；**点了「躺下」就锁死，整局不能起身**
3. **躺下才产生物能、也只有躺着才能建造与升级**。站着不但颗粒无收，而且倒计时结束后只要走进走廊**被静默体碰到就直接出局**——所以这 30 秒要做的事就一件：进屋、躺下、趁气闸没开升几级床和门
4. **资源两条线**：生物能（休眠舱与矿产出）升床/门/炮台/精炼机；合金（只有精炼机产）造修复器、矿与控场道具。**第 6 级起的升级要同时掏两样**，所以精炼机不是可选项
5. **建筑**：哨戒炮（唯一的输出）、精炼机（产合金）、纳米修复器（每秒回舱门 2% 血，每舱最多 4 台）、四座矿（铜/银/金/钻石，合金换生物能产率）、**控场四件**（应急力场 = 门血低于 30% 时 3 秒无敌、束缚弹射器 = 它放技能时概率定住 3 秒、低温阱 = 降它 20% 攻速、粒子加速器 = 本舱炮台 +50% 攻速）
6. **唯一的获胜条件是把静默体打死**（全队一起赢），**没有时间限制**。自己舱室的门被砸破 = 本人出局转观战，队友继续；**全员失压才算失败**
7. 它**只在砸门的时候变强**（啃够一段时间的门升一级），所以「把它打跑」是真能掐断它成长的；血掉到 25% 以下它会撤回气闸**回满血**再出来，但**这一趟必须先啃掉那扇门上限的四分之一**才准走，而且**它回血时不无敌**——把火力铺到来路上就能趁它回血继续磨
8. **帮队友只有一条路：远程修补他的气密门**（花生物能，价格是自己修的 1.5 倍）。谁的门最危险、队友在造什么、静默体盯着谁，全都公开可见。有人出局时他剩下的资源会平分给还活着的人
9. 撑不住可以**「弃守」**：只结束你自己，遗产平分给队友，对局继续（不是投降）

## 十三、人机对战

- 支持游戏：**五子棋、翻转棋、海战棋、点格棋、飞行棋、中国象棋、重力四子棋、UNO、军棋、深空休眠**（扫雷是多人同盘玩法、2048 与俄罗斯方块是各自独立盘竞速，均不支持人机）
- 等待大厅中，**房主**点「添加人机」：人机玩家立即入座并自动准备（昵称带「人机」徽标），人数够即可开始，无需等朋友
- 对局中人机不会秒回（约 1 秒），期间顶部提示会写「XX 思考中…」——这是正常节奏，不是卡住了
- 房间满员即不能再加：双人游戏加一个就满；**飞行棋与 UNO 最多可加 3 个人机**凑满 4 人局（昵称带序号区分）
- 房主可点人机座位旁「移除」把人机请出房间
- 对局中人机由服务端 AI 驱动：五子棋会杀会堵、翻转棋抢角不送角、海战棋会追杀 wounded 舰、点格棋会抢封格且不下送分边、飞行棋会优先撞机并避开对手 1-6 步可达的落点、UNO 会先甩数字牌留住功能牌并在黑牌上选自己最多的颜色，有一定棋力

## 十四、历史战绩

1. 「我的」Tab → 「历史战绩」
2. 列表按时间倒序显示每局：游戏图标、时间、玩家、你的结果徽标（胜/负/平，扫雷显示结算排名）
3. 点击任意一条展开**最终局面快照**：五子棋/翻转棋显示终局棋盘，扫雷显示全部雷位与各家统计，海战棋显示双方布阵与炮击记录
4. 只记录**有结果**的对局（正常终局、认输、断线判负）；开局前解散的房间不记录；下拉分页加载更早记录

## 十五、游戏规则帮助

随时可查每个游戏的完整规则（玩法、操作、胜负判定、小技巧）：
- **大厅**：「游戏」Tab 每张游戏卡片右侧的「?」按钮
- **房间中**：房间页游戏类型旁的「?」按钮
- **对局中**：对局页顶栏的「?」按钮（不遮挡棋盘）
- 弹窗打开时按返回键直接关闭弹窗，不会退出页面

## 十六、断线重连

- **只有对局中（游戏中）才有掉线概念**：一方掉线（关 APP/断网/来电话），对方页面出现「对方已断线」提示，**座位保留 120 秒**，对局暂停不判负
- 掉线方重新打开 APP/网页，用**原账号**进入「房间」Tab 输入房间号重进，棋盘完整恢复，继续对局
- 超过 120 秒未回来：判掉线方负（扫雷中掉线超时按淘汰处理）
- **UNO 是回合制**：轮到掉线的人时，服务端会替他摸一张并过牌（提示「XX 已掉线 · 自动过牌」），不让全桌等满 120 秒；他人回来后立刻恢复正常操作
- **等待大厅里没有「掉线」**：还没开局时界面不会显示「断线」（人真的走了，房间会在 1 分钟内自动回收）

## 十七、返回与退出操作

- 弹窗打开时（创建房间/修改昵称/退出确认等）：返回键**关闭弹窗**，不离开页面
- 对局中按返回：弹「确认退出/再想想」二次确认，误触不会直接掉线；对局已结束则直接返回
- 主页面（底部四 Tab）：第一次返回提示「再按一次返回退出 GameHub」，2 秒内再按才退出 APP
- 网页端浏览器返回键语义相同：主页面双击返回离开站点

## 十八、下载 APP 与更新

- **手机浏览器**：「我的」页点「下载 APP」，浏览器下载 APK 后安装（首次安装需在系统设置允许"安装未知应用"）
- **APP 内**：「我的」页点「检查更新」；每次启动 APP 也会静默检查一次，有新版弹窗提示，确认后自动下载并拉起安装
- **PC 浏览器**：不显示下载入口（建议用手机或下载 APP）

## 十九、管理员

管理员账号在 `server/config/config.json` 的 `admin` 段配置（该文件不进版本库）。
**没有默认口令**，首次部署时自己填；改口令用环境变量 `ADMIN_PASSWORD` 启动一次即可（会覆盖已存在的账号）。
「我的」页多出「用户管理」入口：

- 搜索/翻页查看全站用户
- **封禁/解封**：被封用户无法登录
- **设为管理员/取消管理员**：不能操作自己

## 二十、常见问题

| 问题 | 处理 |
|---|---|
| 加入房间提示"房间密码错误" | 向房主确认密码 |
| 房主点了"开始游戏"没反应 | 几秒后会自己重试一次（房间页自愈）；仍无反应请回大厅重进房间 |
| 能同时待在多个房间吗 | 可以，一个人可以同时创建/加入多个房，互不影响 |
| 开始按钮灰色 | 人数未满或有人未准备（房主自己不用准备；可「添加人机」凑人数） |
| 打完一局回到房间要重新准备 | 故意的：终局会把真人玩家的准备状态复位，续开一局要重新表态（人机自动准备、房主不用准备） |
| APP 安装失败 | 系统设置 → 允许本应用安装未知应用 |
| 网页白屏 | 确认后端 50541 端口已启动且安全组放行 |
| 扫雷旗子插错了 | 切到插旗模式再点同一格取消（翻开模式下旗格点击无效）；只有插在真雷上的旗才计入统计 |
| 扫雷踩雷后还能继续吗 | 看难度：初级 1 条命踩雷即淘汰，中级 2 条、高级 3 条，扣完才淘汰（淘汰后转观战）；全员淘汰或挖完即结算排名 |
| 扫雷格子太大/太小、棋盘看不全 | 格子固定 44px 保证点得准，棋盘放不下就**左右/上下滑动**查看（顶部有滑动提示） |
| 翻转棋提示自动跳过 | 当前无合法着法，系统跳过回合，属正常规则 |
| 海战棋找不到对方的船 | 布阵互相保密，靠命中反馈推理：命中后优先打上下左右相邻格 |
| 人机在哪里添加 | 房间等待大厅，房主可见「添加人机」按钮（五子棋/中国象棋/重力四子棋/翻转棋/海战棋/点格棋/飞行棋/UNO/军棋/深空休眠）；飞行棋与 UNO 最多加 3 个 |
| UNO 为什么看不到对手的牌 | 牌类游戏的基本规矩：对手那一栏只显示「还剩几张」，牌面只有本人能看到 |
| UNO 被 +2 了怎么办 | 手里还有 +2 可以再打出去把罚牌转给下家（+2 只能压 +2、+4 只能压 +4）；接不上就一次摸完累计张数并停一轮 |
| UNO 摸牌后为什么只能出那一张 | 规则如此：摸过牌的这一轮只能出刚摸到的那张，不想出就点「过牌」 |
| UNO 点手牌没反应 | 不是你的回合，或这张牌现在不能出——能出的牌会上移一档并带一圈描边 |
| UNO 认输后其他人还在打 | 故意的：认输只让你出局，牌局继续，只剩一个人时才结算 |
| 历史战绩里没有刚才那局 | 无结果的對局不记录（开局前解散/全员中途退出）；下拉刷新重试 |

| 飞行棋飞机怎么突然多走了几格 | 踩到自己颜色的格子会向前跳到下一个同色格（+4）；踩到**自己颜色那条**虚线的起点格会沿虚线飞 12 格到另一个同色格。界面上会提示「同色跳格！」/「沿虚线飞行！」 |
| 飞行棋虚线箭头是什么 | 每人一条的捷径，横穿自己那条臂的终点航道；踩到起点格就飞过去 |
| 飞行棋格子上的红圈是什么 | 危险格：对手 1~6 步内能踩到，落上去下一手就可能被撞回基地 |
| 飞行棋两架飞机叠在一起 | 同色多架同格叫「迭子」：敌机不能飞越，正好落上来则同归于尽（双方回基地） |
| 飞行棋为什么这架飞机点不动 | 它的前进路径被对手的迭子挡住了（迭子不可飞越），换一架走 |
| 点格棋为什么对方一直画 | 对方封住了格子获得额外回合（连锁封格），画到没格可封为止 |
| 2048 对方和我出块一样吗 | 一样，同种子公平竞速，出块序列完全相同，比的是操作 |
| 2048 要先等别人走完吗 | 不用，各玩各的盘，随时可以滑；只有最终结算要等全员结束 |
| 2048 我先打完了能走吗 | 能，认输/退出只结束你自己（排名垫底），其他人继续；也可以留在页面上等 |
| 后端重启对局会断吗 | 不会，对局实时落盘，重启后客户端自动重连即回到原局 |
