# 终极井字棋 Implementation Plan

> **For agentic workers:** Use the approved design below; steps use checkbox syntax. The user has explicitly authorized direct implementation on dev/wqqxxx. Independent engine and UI tasks may run in parallel; the coordinator owns integration and final review.

**Goal:** 在 GameHub 完整接入封盘版终极井字棋、三档人机与已确认的手机交互。

**Architecture:** 服务端纯引擎产生权威盘面和带目的地的合法落点，房间层负责身份/版本/落盘，WS 复用开局、同步和机器人调度。客户端只展示权威状态，概览/历史共享棋盘组件。

**Tech Stack:** 现有 Python/FastAPI、pytest、Expo 57/React Native/TypeScript；不新增依赖。

**Spec:** `docs/游戏设计/终极井字棋/设计.md`（2026-11-03 用户已批准）。

## Global Constraints

- 当前 `dev/wqqxxx` 原地开发和提交，不创建其他分支；不推 main，不构建/发布 APK。
- 9×9 嵌套封盘规则，X 先手，和棋小盘不归双方，全部小盘结束无大盘三连则和棋。
- 正常不限时；沿用 120 秒断线规则；客户端不复制裁决、合法落点或目的地判断。
- 放大格触控至少 44px，预览后单独确认；颜色来自 theme，支持返回双路径与离线防错。

## Review Focus

- 本手关闭自身并指回自身：下一手自由选盘；预览和真实动作须一致（Task 1）。
- 重复提交与热重启后的过期确认：无额外落子、正常重连恢复（Task 2）。
- AI 搜索期间认输/续开：陈旧结果不得进入新局（Task 2）。
- 320×640 下操作不可裁掉，确认前不发动作、离线/权威更新撤销预览（Task 3/4）。
- 终局回大厅、换座先手、历史结果/快照和其他棋类不回归（Task 2/4）。

## Shared Interfaces

- 游戏键 `uttt`；路由 `UltimateTicTacToe`；路径 `uttt/:code`。
- 引擎 `create_game() -> dict`：`boards: int[9][9]`（小盘/格均行优先 0..8）、`local_results: int[9]`（0未结束/1X/2O/3和）、`active_board: int|null`、`next: black|white`、`winner: black|white|draw|null`、`reason: str|null`、`revision: int`、`moves: {board,cell,color}[]`。房间层增加 `player_colors: {uid: black|white}`。
- `legal_moves(gs) -> list[tuple[int,int]]`；`apply_move(gs, board, cell, color) -> str|None` 原地成功更新所有字段，失败返回中文错误且不改状态；不在引擎内碰版本入参，成功引擎自身 revision+1。
- `game_to_sync(gs, user_id) -> dict`：上述公开盘面加 `your_color`，`legal: {board,cell,next_board,winner}[]`；`next_board` 表示该合法动作后对手目的地，null为自由，`winner`为该动作后的终局或null。该函数不能泄漏可变引用。
- `snapshot(gs) -> dict` 包含 `game:'uttt'`、公开盘面/归属、最后动作、胜负原因，用于历史最终盘面。
- AI `normalize_difficulty(value) -> easy|normal|hard`，`best_move(view, difficulty='normal', time_budget=None, rng=None) -> tuple[int,int]|None`；不改入参。普通约0.15s、困难约0.5s，有界搜索。
- C→S：`uttt_move {board,cell,revision}`；S→C：`uttt_state {game,actor_id}`。`game_start` / `sync.game` 使用同一视图，身份逐人下发；失败回 `error`，陈旧版本另补当前 `uttt_state`。终局同时发 `game_over`、大厅状态，下一局须回大厅准备。
- Socket `utttMove(board:number, cell:number, revision:number)`；TS `UtttState` 与上述视图同形。`UtttBoard` 共享展示组件接 boards/local_results/active_board/focus/pending/nextBoard/lastMove/onSelect 等展示参数，禁用规则由调用方权威数据决定。
