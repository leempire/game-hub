## 两端接口

- `Card = {id:number, rank:string, suit:string}`，花色 `S/H/D/C`，王为 `SJ/BJ`，无花色写空串。点数用 `2…10/J/Q/K/A`。`Combo = {kind:string, rank:string, cards:Card[], wild:{id:number,rank:string,suit:string}[]}`，`kind` 为 `single/pair/triple/full_house/straight/tube/plate/bomb/straight_flush/joker_bomb`，`rank` 为实际比较牌点。
- `guandan_action` 包含 `action: play/pass/return/next/hint/preview`、`match_id`、`revision`、`deal`，出牌或预览用 `cards:number[]`，还牌用 `card:number`。提示和预览透传可选 `request_id:number`，分别回 `guandan_hint` / `guandan_preview`，带同一版本、已解析的 `combo` 或 `null` 以及可选 `message`。普通动作广播逐座 `guandan_state`。
- `game_start.game`、`sync.game` 和 `guandan_state.game` 都是 `{game:'guandan', match_id, revision, phase, deal, players, levels, level, level_team, current_id, hand, remaining, passed, finish_order, last_play, exchange, return_choices, lead_reason, deal_result}`。`players` 为四个 UID 按逆时针顺序排列，相邻不同队，`levels` 为两队级别。`phase` 是 `returning/playing/between/finished`。`current_id` 在并行还贡或结副为 `null`，`remaining` 按席为 `number|null`。`last_play` 为 `{uid, ...Combo}` 或 `null`。`exchange` 为 `{antitribute,lead_id,pairs:[{from_id,to_id,tribute,returned,submitted}]}` 或 `null`。`return_choices` 为自己的合法牌 ID。`lead_reason` 为 `first/pass/partner/tribute/antitribute` 或 `null`。
- `DealResult = {deal, winner, finish_order, levels, advance, level}`，`winner` 为队号 `0/1`，双下两席不进入 `finish_order`。其余已知名次按顺序给出。`summary = {match_id, players, levels, deal, winner, reason, deal_result}`，`reason` 为 `clear_ace/surrender/leave/disconnect` 或 `null`。整场 `game_over` 带 `game:'guandan'`、`match_id`、`summary`。结束后 `sync.guandan_result` 复用整场终局消息。
