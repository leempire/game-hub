GameHub 图标草稿

四类草稿：应用 Logo（六芒星 + 外接圆，3 个方案）、五子棋入口图标（3 个方案）、扫雷入口图标（3 个方案）、黑白棋入口图标（下版本新游戏，3 个方案）。每个方案都按真实使用尺寸预览（96 / 48 / 32 / 16px），小尺寸下的可辨识度是选型关键。

审阅方式：直接回复组合，如 Logo B，五子棋 A，扫雷 C，也可以指出想微调的点（颜色 / 线宽 / 元素增减）
LOGO

应用 Logo · 六芒星 + 外接圆

几何参数：外接圆与六芒星顶点共圆（半径 32 / 96 视口），星由两个等边三角形叠成。用于 APP 桌面图标、网页 favicon、登录页品牌位。

LOGO A线条版

星恰好内接于外接圆，纯线框、气质轻盈，适合登录页大尺寸品牌位与单色场景。短板：16px 下线条偏细，不宜做 favicon。

LOGO B实心徽章版

靛蓝圆盘 + 白色星形镂空，对比度最高，16px 依然锐利，推荐做 favicon 与桌面图标。圆形轮廓在 iOS/Android/浏览器三端都不吃裁切。

LOGO C渐变应用版

圆角方形渐变底 + 白线星圆，最接近主流 APP 图标的质感，符合 Android 自适应图标安全区。可与 B 搭配：C 做桌面图标、B 做 favicon/登录页。

GOMOKU

五子棋入口图标

现状是两个小圆点（棋子语义有了但太弱）。三个方案都围绕"线交叉点上的黑白子"这一五子棋本质元素，替换游戏入口卡片的 32~40px 图标位。

五子棋 A交点三连

木色棋盘 + 黑三子斜连、白子两端封堵——一图讲清"连线"与"对抗"两件事，棋盘配色与游戏内棋盘一致，元素最完整。推荐。

五子棋 B斜五连极简

无底板，五颗黑子斜连一线 + 两颗白子。"五子连线"语义最直接，透明背景适配任何卡片底色，笔画少、小尺寸最稳。

五子棋 C黑白对峙

2×2 网格上黑白两颗大子对角相抵，对抗张力拉满、远看最醒目。短板：没有"五连"语义，更像围棋/黑白棋的气质。

MINESWEEPER

扫雷入口图标

现状是通用 grid 图标（完全看不出是扫雷）。三个方案取自扫雷最标志性的三个元素：地雷、旗子、立体砖格。

扫雷 A经典地雷

圆体 + 八向尖刺 + 高光，全球通用的扫雷符号，零解释成本，任何尺寸都可辨识。透明底，放卡片里最百搭。

扫雷 B标旗砖格

立体斜面砖格 + 红旗，复刻游戏内最高频的"标旗"动作，砖格质感与 APP 内扫雷棋盘一致，玩过的人秒懂，老玩家有情怀分。

扫雷 C砖格藏雷

B 的砖格里藏着 A 的地雷，"格子底下有雷"的玩法本质一图说尽，语义最完整。短板：元素多，16px 下雷的细节开始糊。

REVERSI

黑白棋（翻转棋）入口图标

下版本新增游戏的入口图标。黑白棋的标志元素：绿棋盘、黑白双面棋子、"翻转"这一核心动作、中央对角四子的开局定式。

黑白棋 A翻转碟

绿棋盘上一枚半黑半白、正在翻转中的棋子——把黑白棋独有的"翻面"动作凝固在图标里，与五子棋/扫雷图标同为"棋盘+关键元素"语言。推荐。

黑白棋 B半黑半白极简

无底板，一枚倾斜 15° 的双色棋子，翻转的动态感最强，任何卡片底色都适配。短板：没有棋盘语境，单独看可能误读为围棋子/阴阳符号。

黑白棋 C开局四子

绿棋盘 + 中央对角黑白四子——黑白棋全球统一的开局定式，老玩家一眼认门。短板：静态感强，"翻转"语义要靠知识补全，16px 下四子偏小。

选定后的落地动作（供参考，本页只是草稿评审）

  • 游戏入口图标：接入 GamesTab 卡片图标位（react-native-svg 组件，三端一致渲染），同时给下个版本的翻转棋入口配同风格图标
  • 应用图标：app.json 的 icon / adaptiveIcon（由选定 SVG 导出 1024px PNG）+ 网页 favicon + 登录页品牌位（替换现在的游戏手柄 Ionicons）
  • 所有几何参数已记录在 SVG 源码中（星/圆半径、线宽、配色取自 app 主题），选定后可继续微调颜色与粗细再落地
