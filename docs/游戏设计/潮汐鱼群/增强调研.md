# 潮汐鱼群调研

- 成长循环采用可立即理解的体型门槛，进食反馈直接反映在体型和分数上。[Dingo Games 官方发行页](https://store.steampowered.com/app/345200/Tasty_Blue/) · [GameCreator 作者的机制演示](https://gc.gamecreator.com.cn/forum/det/6494)
- 复活时采用安全出生点与独立的无敌计时，命数耗尽后观战。[Epic 岛屿设置文档](https://dev.epicgames.com/documentation/fortnite/island-settings-in-unreal-editor-for-fortnite)
- 触屏通过拖动直接选择游动方向，桌面支持方向键，场内持续用轮廓提示危险。首版采用同图积分竞速，玩家互相穿过，满足好友同场且无伤害的要求。关卡脚本和玩家互食会改变这一范围，留待独立设计。

- 10 分钟局采用阶段性强度和间歇性事件。玩家先在小鱼较多的海域熟悉操作，中后期再出现更大的捕食者。事件提前五秒预告，结束后回到常态。固定节奏便于同房比较成绩，也方便验证不同成长速度。参考 [Valve 的局内强度节奏演讲](https://steamcdn-a.akamaihd.net/apps/valve/2009/GDC2009_ReplayableCooperativeGameDesign_Left4Dead.pdf)。
