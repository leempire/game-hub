# 潮汐鱼群

1–4 人同海域，新开对局最长 10 分钟。吞食较小的野生鱼可成长并得分，更大的野生鱼会吃掉玩家。玩家之间可自由穿过。每人三条命，前两次被吃后立即在较安全处复活，保留成长并无敌 3 秒，第三次进入观战。时间到或无人能继续时结算，同分并列，退出者不参与名次。

等待大厅提供小、中、大三档海域，道具和事件独立开关。海流珠加速 5 秒，护盾珠抵挡一次吞食。鱼群迁徙带来额外小鱼，急流期提高野生鱼游速。场内显示生命、分数、倒计时、成长进度和海图。鱼群迁徙和急流在开始前五秒预告。镜头会随体型增加逐级拉远。出局后可切换存活的观战对象。触屏拖动水域，键盘使用 WASD 或方向键。

服务端以固定 30 Hz 步长模拟，每三步广播共享快照。移动消息仅提供方向。客户端插值绘制鱼群，对本机移动即时预测并随快照矫正。静态背景压缩为 WebP，音乐和音效在玩家开启后播放。

## 长局节奏

- 体型共有七档，累计积分达到 0 / 7 / 28 / 85 / 220 / 560 / 1200 分时依次解锁。出生点优先远离威胁，并考虑附近的猎物。玩家长大后游速缓慢下降，较宽松的捕食判定让小鱼有余地脱身。
- 前 90 秒以小鱼为主。第 90、225、390、510 秒逐步引入更大的野生鱼，并将新捕食者放在离玩家较远的区域。
- 10 分钟内交替出现四次迁徙和四次急流。迁徙持续 22 秒，额外小鱼会在事件结束后退场。急流持续 16 秒，野生鱼加速 35%。道具每 6 秒尝试补充，未拾取的道具约 30 秒后退场。
- 从旧存档恢复的对局保留原来的 2 分钟结束线，新开的对局使用 10 分钟。

## 美术与声音

海底背景由内置 ImageGen 生成后压缩为 WebP。鱼类使用自制双帧透明贴图，青绿代表可吞食目标，珊瑚红和外圈共同标记威胁，蓝色描边标识本机鱼。中后期的大型捕食者有独立剪影和虚线危险圈，两类海域事件有独立色调。进食、成长、受击和道具有短暂的场内反馈。贴图与原创合成器配乐、吞食、成长、受击、道具、事件、结算音效一同置于 [app/assets/fish](../../../app/assets/fish/)。

## 验证记录

本机 Chromium 双浏览器验证了房规、触屏和键盘操作、音乐播放、返回确认、双端结算。上行模拟 120 毫秒、下行模拟 80–135 毫秒时，本机鱼在服务端更新前已移动。使用大图密集鱼群，2 秒采样约为 60 次浏览器绘制回调每秒，P95 回调间隔 16.8 毫秒。另在本机用四人、大图和双开房规跑满 3,600 模拟帧，P95 模拟和快照编码耗时合计约 0.23 毫秒，快照 JSON 峰值约 2.1 KB。帧率、耗时和玩法手感仍需在不同性能的 Android 真机与实际网络上验证。

10 分钟版在双浏览器验证了倒计时、触屏、成长、受击复活、事件预告和双端结算。四组四人自动走位模拟中，三局打满 600 秒，一局在 574.2 秒全员出局。本机 P95 单步模拟和快照编码约 0.19 毫秒，快照 JSON 峰值约 2.1 KB。自动走位结果用于检查节奏和上限，仍需真人试玩校准成长速度。
