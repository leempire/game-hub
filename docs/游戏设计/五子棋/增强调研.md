# 五子棋增强调研


## 2026-11-04：统一三档人机

简单：所有合法空位随机。普通：原 0.15 秒搜索；困难：0.5 秒。普通/困难先兑现一步胜与唯一必堵。

采用「有界迭代加深 + 合法动作随机/策略分档」。不采用改变骰子、资源费用或读取隐藏信息提高强度；保留无参调用的普通档兼容性。难度存在每个 bot 身上，可混合添加；搜索用输入副本在线程池运行，结束/续开后丢弃旧结果。

来源（中英文交叉核对）：
- [游戏难度与搜索评价研究，北京大学](https://ai.pku.edu.cn/docs/2021-07/20210715220553957416.pdf)：区分预算与实际表现，随机游戏需要多局测量。
- [Columbia：Alpha-Beta pruning and Checkers](https://www.cs.columbia.edu/~devans/TIC/AB.html)：时间预算迭代加深，完成一层才采纳结果。
- [TalTech：Game AI heuristics, difficulty, performance](https://courses.taltech.akaver.com/programming-in-csharp/lectures/game-ai-heuristics-difficulty)：搜索深度、预算及随机合法着法用于调节强度。

验证：`cd server && python test/bench_ai_difficulty.py --games 8`。固定战术局面，8 个随机种子下正确选择次数：

| 简单 | 普通 | 困难 |
|---|---|---|
| 0/8 | 8/8 | 8/8 |

这是固定种子的小样本能力检查，不能据此估计 Elo 或保证每局困难都胜过普通。困难档代表更大搜索预算或更完整的策略；合作游戏指队友执行能力更强。全部动作仍由引擎校验。


## 2026-11-04：尺寸与黑棋禁手

房间设置棋盘 9/13/15/19 路，默认15；`gomoku_forbidden` 默认关闭。开启时按 RIF 的黑棋长连、双四、真双三约束，精确五连优先，白方长连仍胜。服务端拒绝禁手点且不改盘，客户端仅渲染权威 legal，防止用户误触被罚。只采用禁手规则，不引入比赛开局换手或指定布局。

双三不是字符串匹配两个“三”：只有能合法延伸成两头均可成五的连续四才算真活三；延伸点若自身构成长连/四四/递归禁三则排除。`gomoku_rules.py` 用显式假设棋盘与有界缓存递归判断，不读取时钟或网络。`gomoku.legal_moves(board,player,forbidden)`、`forbidden_reason`、`check_win(...,forbidden)` 均按实际尺寸。AI 对实际提交着法再过滤禁手，搜索中仍为局面启发式。

来源：[国际连珠联盟规则9.2–9.3](https://www.renju.net/rifrules/)、[中国棋牌中心五子棋规则](https://www.sport.gov.cn/qpzx/n27319064/n27319033/c29229339/part/29229549.pdf)。采纳双三递归与五连优先；不采用完整赛事开局，因为本轮目标是现有房间房规。

开启禁手后若轮到黑方且所有余空点均为禁手，黑方无合法落点判负（`no_legal_moves`），不要求玩家尝试非法位置，也不等待无限回合。该条是本作对不提供pass动作的房间玩法的终盘约定。
