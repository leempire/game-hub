# 中国象棋增强调研

2026-11-04，覆盖记谱、长将与棋钟；不改变原有走法与困毙判负。

## 采纳

- [皮卡鱼开源社区程序竞赛规则](https://www.pikafish.com/rule.html)第二章第六节给出四字记谱、双方视角的路数、前后同子与多兵的区分；服务端在落子前生成中文记谱，红方中文数字、黑方阿拉伯数字，随每手增量下发并留入战绩。
- 同一来源第三章及[世界象棋联合会规则](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_XiangQi_Rules_English2018.pdf)第19.8条把持续照将和重复局面联系起来。实现采用程序竞赛常用的第三次同局面裁决时点：局面含行棋方，在两个完整循环内，一方每次走子都将军、另一方没有每次将军，判单方长将负。双方均持续将军时和棋；普通重复不冒充长将，继续沿用既有无吃子120半回合判和。
- [FIDE棋钟规则](https://handbook.fide.com/chapter/e012023)说明双方各有用时，完成一步后停止本方并启动对方。这里采纳独立的剩余时间与显式时间差输入，默认不限时；服务器负责真实时间和到期调度，纯引擎不读取墙钟。象棋另可选0/10/30秒单段读秒房规；主时用尽的同一手只扣超出主时的部分，完成一手后下一次轮到自己重新获得一段完整读秒。该模式参考[ShogiBoardQ作者的读秒说明](https://hnakada123.github.io/ShogiBoardQ/zh-cn/guide/time-control.html)，是本项目可选房规，不称为全部象棋赛事的统一制式。
- 人机练习悔棋回退最近双方各一步，恢复棋盘、吃子、记谱、无吃子计数与重复序列；终局后禁止悔棋。房间层检查仅房主、恰好一个人机且房规开启，并使搜索版本失效。

## 暂不采纳

- 不把普通三次重复全部判负，也不声称实现了全部WXF长捉、长杀和循环禁例；本轮明确处理的是长将。
- 不退款已消耗的棋钟时间，避免通过反复悔棋额外获益。
- 不引入客户端裁判、客户端上传剩余时间或无限搜索。棋钟到期与合法落子由同一服务器串行结算。

## 断线与重启口径

对局中单方或双方断线仍继续走当前棋钟，防止靠断线停表；既有120秒断线判负独立生效，先触发者结束对局。服务器停机间隔不扣时：只保存剩余毫秒，恢复后重建单调时钟锚点，不把旧进程的时间戳用于新进程。悔棋不退款已消耗时间。

### 公开重复历史与人机长将防护

`best_move(board, color, ..., game=None)` 保持旧盘面接口兼容；真实机器人另传公开棋局副本。提供历史时，仅在根层用权威引擎试走候选，排除会立即触发己方单方长将判负的着法；若全部候选都判负则仍返回合法着，正常接受裁决。此防护适用于三档，不改变搜索预算，也不预判更深层重复。象棋没有暗子，棋盘与重复序列均为公开信息；线程内使用独立副本，不改动在线状态。

回归用两轮真实车将军与将往返序列，证明下一步继续将军立即判黑胜，而三档在存在替代着时均避开该着，并验证输入不变、旧接口及无可避免判负的合法兜底。
