# 海龟汤增强调研

2026-11-28，中英文检索规则、AI 主持及移动端玩法。后续用户指定：不用自编题，收集多批公开题目，随机抽取并排除玩家已玩题。

## 规则与交叉验证

- [moses 出版方 Black Stories 规则](https://www.moses-verlag.de/black-stories/)采用一名掌握正反面的主持人和共同推理的团队；还原事件的主要经过即可揭晓，不要求逐字背诵。采用合作解题和固定真相，不让 AI 临场改汤底。
- [Detective Stories 玩法](https://detective-stories.com/faqs)让推理者问可用 yes / no / I don't know 回答的问题；理解故事后由主持人宣布 solved。按用户要求，统一显示「是 / 否 / 不确定」，最后一项也用于未设定、无关、问题有歧义或混合前提的情况。
- [海龟蘑菇汤开发者介绍](https://www.findthelamp.com/)提供 AI 主持、单人/多人和原创故事分享，说明 AI 主持不必占一个真人席位。采用 1–8 名真人加独立 AI 主持；不提供 AI 猜题人机。
- [Hi8 海龟汤](https://hi8.com/g/haiguitang)采用是非问答、独立的「我来还原」和共享好友房，提供有上限的提问过程。采用「提问」与「猜汤底」明确分开，普通问句即使涉及关键线索也不自动结局；整段推理须还原核心事实且无关键矛盾。
- [LatEval 研究及公开数据](https://github.com/THUKElab/LatEval)使用不完整故事、完整真相和关键线索评估模型，说明需要独立的事实覆盖判断；不直接把模型自由生成的文字当成裁判结果。

## 采纳与不采纳

| 决策 | 理由 |
| --- | --- |
| 固定题库按参与者历史排重 | 用户明确要求公开题，不生成新题；新老玩家同房时排除所有人的已玩集合。 |
| 开局即记录已玩；全员均未玩过才能抽中 | 避免中途退出刷题或同一账号跨房重复抽到；已见汤面的题也算玩过。 |
| AI 只返回受限枚举和判定字段 | 页面按白名单生成回复，避免提示注入让模型直接把汤底发给玩家。 |
| 输入分为「提问」「猜汤底」 | 拒绝普通问题误触发通关；允许语义等价的完整推理，不要求人名、时间等枝节逐字一致。 |
| 每房同时一个主持请求、最多 80 次提交 | 避免多个人抢答导致上下文互相矛盾，限制长局的文本/成本增长；错误请求仍留失败记录且不自动重试。 |
| 汤面固定卡、问答按时间线、底部固定输入 | 手机可随时回看已确认事实，等待主持时明确显示忙碌，发送立即清空，失败按编辑版本恢复草稿。 |
| 房主确认「结束并揭晓」可放弃 | 卡住或积分不足时仍有退出当前题的明确通路；揭晓只影响当前局。 |
| 不采用自由生成题、经典题改结局、AI 主动给答案 | 用户指定不自编；稳定真相也有利于判定一致和玩家排重。 |
| 不提供公开战绩汤底 | 分享只带汤面和结果，避免给尚未玩的人剧透；参赛者个人战绩可回看答案。 |

最终来源、批次及许可见下节和题库 README。运行时只读服务端题库，客户端资产不含汤底。

1. [JQW2006 公开题库](https://github.com/JQW2006/turtle-soup/blob/main/backend/app/data/puzzles.json)：14 道经典中文题，去掉同故事的 8 个英文版本，使用上游 MIT 许可和已有关键事实。

AISoupGameWeb 虽然代码用 MIT，但 README 另行声明附带题目的版权归属不明，因此未采用。题库文件、逐题来源和许可正文见 `server/content/turtle_soup/`。不得把代码许可证直接当成被明确排除的题库内容许可。排重使用稳定的 family，标题或措辞变化不重置账号记录。

## 渐进提示与发送反馈（2026-11-28）

[AI TRPG 提示设计](https://ai-trpg.com/ja/umigame/guide)按进展区分给方向、提醒回看已知问答和提醒线索已齐；[Hi8 海龟汤](https://hi8.com/g/haiguitang)采用有限提示，避免直接递送完整答案。按用户要求加入自动适量提示：同一主持调用判断是否跑偏/没方向，服务器决定频率，并使用预先校对的分级提示文案，不把模型自由文字直接发给玩家。

采纳每题最多三档、逐步具体、相邻提示至少隔几次有效提交；连续没有进展也触发提示，正常推进时不连续插话。不新增模型调用、不自动代玩家猜底、不提前发送整组提示或汤底。原题面/汤底保持来源原文，辅助提示依据固定故事整理。

发送输入改为乐观清空：点击发送立即清空已提交文本，成功/错误猜底回包不再改写输入；明确被拒、主持失败或重连确认未收到时，仅在玩家未编辑新草稿的情况下恢复旧文本。
