# 掼蛋规则与数字牌桌调研

调研日期 2026-11-26。以淮安现行地方标准 DB3208/T 235—2025 第 5 至 8 章为主，核对总局棋牌中心审定的 2022 年试行规则、世界赛规则英文版，以及中英文线上产品的实际口径。具体赛事可以采用补充规程。 [淮安现行标准及全文](https://dbba.sacinfo.org.cn/portal/online/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2) · [总局赛事说明](https://www.sport.gov.cn/n20001280/n20067662/n20067613/c26817937/content.html) · [2022 规则原文转载](https://www.52hrtt.com/sa/n/w/info/F1702965842341) · [世界赛规则英文版第 7、8 条](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf)

## 共同规则

- **座位和发牌。** 四人对家搭档，两队各两人。两副牌共 108 张，每人 27 张。逆时针出牌，从本人看依次是本人、右侧下家、对家、左侧上家。 [术语标准](https://std.samr.gov.cn/db/search/stdDBDetailed?id=F43F860A4CB341D9E05397BE0A0A2F6E) · [宿迁协会规则 §4–5](https://www.ttbz.org.cn/upload/file/20191223/6371270213033087899544901.pdf) · [世界赛规则 §7–8](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf)
- **级牌和逢人配。** 双方从 2 起步，一副牌使用同一个级别。单张由大到小是大王、小王、本副级牌、其余普通点数（A 到 2）。级牌在连续结构中按原点数排。两张红桃级牌是逢人配，打成组合可替代非王牌的点数和花色，单出按本副级牌。两张同种王能组成对子，大小王混搭不能成对。 [淮安 §6](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=6) · [世界赛 §7.6–7.7、§8.5](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf) · [play.cards 规则](https://play.cards/rules/guandan#combinations)
- **牌权。** 领出可用任意合法牌型。跟牌可以过，也可以用同型且更大的牌或按炸弹层级压制。先前过牌的人遇到新的有效牌，转回其座位时仍可跟。其他还在打的座位都过后，最后出牌者取得下圈领出权。获领出权的人已经走完时，接风规则决定谁领。 [2022 规则第 4、8、9 条](https://www.52hrtt.com/sa/n/w/info/F1702965842341) · [play.cards 行牌](https://play.cards/rules/guandan#gameplay)

| 牌型 | 固定结构与比较 |
| --- | --- |
| 单张、对子、三同张 | 1、2、3 张同点，按牌点比较。 |
| 三带对 | 三同张和一个异点对子，只比较三同张。 |
| 顺子 | 恰好五张连续点数，`A2345` 最小，`10JQKA` 最大。 |
| 三连对 | 恰好三组连续对子，`AA2233` 最小，`QQKKAA` 最大。 |
| 钢板 | 恰好两组连续三张，`AAA222` 最小，`KKKAAA` 最大。 |
| 同点炸弹、同花顺、四王炸 | 同点炸弹从 4 张起，先比张数再比点数。同花顺恰好五张，比较顺子点数。两大王和两小王组成四王炸。 |

普通牌型只互压同类。炸弹从低到高为四张炸、五张炸、同花顺、六张及以上同点炸、四王炸。花色用于识别同花顺和实体牌，同强度的牌不以花色分胜负。连续结构允许 A 作首或尾，`QKA23` 不连。八张同点加两张逢人配可组成十张炸。 [淮安 §6](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=6) · [世界赛 §8.5](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf) · [唐人游牌型举例](https://guandan.uc55.com/Rule/Detail/201801_000209.html)

## 口径差异与 GameHub 首版建议

| 项目 | 来源核对 | 首版建议及原因 |
| --- | --- | --- |
| 结束一副牌与接风 | 总局试行版在双上或三人出完时结束。其接风覆盖头游和二游。淮安 §7.2 明列头游，世界赛 §8.5 将牌权交给最后出牌者的搭档。 [总局第 8–9 条](https://www.52hrtt.com/sa/n/w/info/F1702965842341) · [淮安 §7.2](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=7) | 采用双上或三人出完即结副。头游或二游走完后若无人压，其仍在打的搭档接风。双上时，另两席统一显示「双下」。 |
| 升级与过 A | 淮安及世界赛按头游队的搭档名次升 `3/2/1`。JJ 历史帮助页的双上升 4 级。唐人游采用三次不过 A 退回 2。 [淮安 §7.3、§8.1](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=7) · [JJ 升级](https://www.jj.cn/news/320/20120613160600024346.shtml) · [唐人游升级](https://guandan.uc55.com/Rule/Detail/201801_000209.html) | 采用 `3/2/1`。保留两队的级别，下一副打上一副胜队升到的级别。A 必须实打，只有正在打 A 的一方拿头游且搭档为二游或三游才赢整场。失败保留 A，朋友局可按熟悉的升级节奏继续。 [play.cards 过 A](https://play.cards/rules/guandan#scoring) |
| 单贡、双贡及抗贡 | 总局和世界赛规定，非双下时第四名向第一名进贡。淮安 §7.4.2 的单下条文写的是输方拿二游与末游这一种名次。双下时两人各贡一张，淮安明确允许两名贡方合计持两张大王抗贡。 [总局第 10 条](https://www.52hrtt.com/sa/n/w/info/F1702965842341) · [淮安 §7.4](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=7) · [世界赛 §8.4](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf) | 从第二副起覆盖所有非双下，头游和末游同队时也走单贡。贡当前最强的非逢人配牌。双贡由头游收较大的一张，二游收另一张。同点按进贡者给自己左手上家处理。向头游进贡者领出，抗贡后由头游领出。 |
| 还贡 | 淮安及世界赛采用牌点不超过 10、无符合项还最小。JJ、唐人游各自允许还任意一张。世界赛要求双还贡一起亮出，play.cards 明确排除级牌和王作为常规还贡候选。 [淮安 §7.4.3](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=7) · [世界赛 §8.4](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf) · [play.cards 贡还牌](https://play.cards/rules/guandan) | 常规候选为面值 2–10 的非级牌，无可选时按单张牌力还最小。双还贡选齐才公布并交换，避免先完成的一方影响另一人的选择。 |
| 百搭歧义 | 淮安 §6.9 要求取大优先，两张逢人配加相邻两个对子在领出时按钢板，跟牌可按被压的牌型成钢板或三连对。世界赛要求把百搭放在其代表的位置，必要时声明牌型。 [淮安 §6.9](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=6) · [世界赛 §8.5](https://gawsf.b-cdn.net/files/World%20Guandan%20Competition%20Rules%20%282025%29%20.pdf) | 领出按取大和钢板优先，跟牌优先按同类合法解解释，找不到同类解才检查合法炸弹。展示实际牌和替代结果，减少误用逢人配。 |
| 报牌 | 淮安鼓励出牌后剩 ≤10 张时主动报一次，随后可由有牌权者问。总局试行版使用报牌卡并限制追问，具体赛事可调整做法。 [淮安 §7.1](https://dbba.sacinfo.org.cn/portal/download/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2#page=7) · [总局第 11 条](https://www.52hrtt.com/sa/n/w/info/F1702965842341) | GameHub 始终公开四席精确余牌数，方便对照牌桌上的出牌历史。 |
| 快速场与平台变体 | 总局试行版包含计轮、计副和计时等赛制。腾讯提供不洗牌、翻倍、复式等模式。 [总局第 12 条](https://www.52hrtt.com/sa/n/w/info/F1702965842341) · [腾讯产品说明](https://apps.apple.com/cn/app/id6502691626) | 首版集中验证四人组队打过 A 和跨副贡牌。限副数、比赛计时、各地房规和智能托管可在经典流程验收后评估。 |

## 视觉和交互参考

- 中文产品的开发者说明里，腾讯有一键理牌、牌面尺寸和手牌高度设置。齐盛的产品支持横、竖排列方式的理牌。共同点是长手牌需要整理和放大入口。先采用按点数排列和放大选牌，自动拆分成组涉及策略取舍，留待实际牌局评估。 [腾讯版本记录](https://apps.apple.com/cn/app/id6502691626?platform=vision) · [齐盛产品说明](https://apps.apple.com/cn/app/id1448089228)
- 英文网页 play.cards 用牌型实例、炸弹强度阶梯和升级表呈现复杂规则。GameHub 可把这些要点放进现有规则帮助，并将牌型名称、当前级别和配牌结果放在对局视线中央。 [play.cards 牌型速查](https://play.cards/guandan) · [GameHub 跨游戏设计](../README.md)
- 视觉以低饱和桌布、高对比浅色扑克和固定角标为出发点。桌上保留四席关系、公牌和行动者，手牌选中采用上抬、描边和读屏状态。紧凑牌角给出独立命中区，并提供完整大牌选择。触控与网页目标尺寸分别参考 Apple 44 pt 和 WCAG 2.5.8 的 24 CSS px，按 GameHub 的移动端规范预留主要控件 48 个逻辑单位。 [Apple 交互指南](https://developer.apple.com/design/tips/) · [W3C 目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) · [GameHub 移动端规范](../../移动端体验设计方法论.md)
