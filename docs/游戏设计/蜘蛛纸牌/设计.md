# 蜘蛛纸牌：房间独立接龙

在「各玩各的」中创建或加入 1–4 人房间。成员准备后由房主开始。每人拿到同一副起手牌，在自己的牌桌上进行接龙。房间显示每人的收齐组数与结束状态。

## 规模与规则

- 每人 104 张黑桃牌，十列中前四列各六张，其余各五张，每列开局只翻开顶牌。余牌五轮，每轮给自己的十列各发一张。有空列时先填满再发牌。
- 连续递减的明牌组可以接到恰好多一点的牌或空列。移走暗牌上方的牌会自动翻牌，完整 K 到 A 自动收走。收齐八组即个人通关。
- 移动、发牌和撤销只作用于自己的牌桌。撤销回退自己的最近一步，须确认。每人保留最近 200 步。
- 每人都可以确认「结束我的牌局」。个人通关、结束或离开后可返回房间，仍在局中的玩家可以继续。续开须返回房间重新准备。

## 可解牌局

- 随机洗牌后查找完整通关路径，最多尝试六次，每次搜索预算为 300 个状态、256 步。找到解才采用这副牌。
- 六次均未验证时，使用已回放验证的种子 1。随机重排等高列和五轮余牌对应位置，以保留完整解。验证用的解只留在生成过程中。
- 房间只生成一副牌。线程池洗牌后再检查房间、轮次、成员、房主和准备状态，确认可开局才为每人复制完整起手牌。
- 正式操作和验证共用移动、发牌、翻面和收齐规则，走错仍可能卡住。回归会逐步回放随机与兜底牌局。

## 房间、退出与存档

- `spider` 是 1–4 人普通房间。创建、加入、准备和房主开局沿用公共流程，开局后锁定席位。房间容量最多四人，无人机席位。
- 每步合法操作写盘。断线重连通过 `sync.game` 恢复自己的牌桌，蜘蛛纸牌没有 120 秒判负。全员离线超过公共 `ROOM_IDLE_TTL=1800s` 时回收房间。
- 旧版进行中存档把共享牌桌各自复制一份，保留原有列数、牌序、进度和撤销记录，已退出者的个人牌桌记为结束。续局使用十列标准牌桌。旧个人存档房间容量补为四人。
- 个人结束后座位保留用于战绩，`in_game=false` 让玩家可提前返回房间查看其他人的进度。显式退出的房主把房主身份移交给仍在局中的玩家。
- 全员结束后房间回 `waiting`，保存一次战绩。个人通关记为「胜」，主动结束或离开记为「结束」。历史战绩返回本人牌桌，分享链接返回发起者的最终牌桌。旧共享战绩沿用原快照。

## 同时操作与协议

- `game_start {room,game}`、`sync.game` 和 `spider_state {game,actor_id}` 各自只发送给对应玩家。
- `spider_action {action:"move"|"deal"|"undo"|"end", revision:int, source?:int,index?:int,target?:int}` 校验个人牌桌版本。列和牌的索引从零开始。失败时只向请求者发送 `error` 和当前个人视图。旧 `new` 动作提示回房开新局。
- 当收齐组数或结束状态改变时，广播 `lobby` 更新 `room.players[].spider_progress`。全员结束后广播 `game_over {winner:"end",reason:"all_finished"}` 和等待大厅状态。
- `game` 包含 `columns:(number|null)[][]`、`total_runs`、`stock_count`、`completed`、`move_count`、`revision`、`can_undo`、`can_deal`、`legal_moves`、`finished`、`winner`、`reason`。暗牌用 `null` 表示。`departed` 保留为空数组，供旧客户端解析。
- 客户端忽略旧版本牌面。其他人公开进度的更新只改玩家栏。新一轮的起始版本大于上一轮所有人的最后版本。

## 手机交互与验证

- 牌宽 54px，明牌露出至少 44px。牌桌横向滚动，长列纵向滚动。深绿牌桌与白字的对比度为 12.18:1，颜色来自 `theme.ts`。
- 显示个人组数、步数、房号、连接状态及其他玩家的收齐进度。发牌剩余轮数按实际列数计算。点选牌组后目标列显示「可放」。
- 发牌、撤销、提示、结束、离开固定在牌桌外。结束、撤销和离开有确认，接 `useModalBackGuard` 与 `onConfirmLeave`。个人打完可以提前返回房间，全员打完显示公共结算界面。
- 历史快照复用 `SpiderBoard`。旧快照缺 `total_runs` 时按八组展示。
- WS 回归检查逐人下发、独立操作、版本冲突、结算、历史和分享。双浏览器在 320px 和 390px 竖屏网页验证分类入口、触控操作、刷新续玩、退出续开和战绩。

## 横屏全屏（2026-10-23）

- 牌桌可视区域右下角固定“全屏”按钮，文字加图标、触控高至少 44px；进入后同一位置显示“退出全屏”。只改变本机显示，不重建牌桌、连接或牌局，不发送游戏动作。
- 全屏隐藏导航标题、收齐槽和结束/离开行，保留个人收齐计数、步数、状态、提示和牌桌操作。牌桌仍支持横竖滚动。
- APP 复用 Native Stack 的 `orientation: landscape`、`navigationBarHidden` 和 `autoHideHomeIndicator`，以及已有 `expo-status-bar`；应用支持方向改为 default，所有路由默认 portrait，仅此屏全屏时覆盖，退出恢复竖屏。维护者重新构建后原生配置生效，不改 versionCode、不由协作者构建 APK。
- 浏览器在用户点击时申请 Fullscreen API，再尝试 `screen.orientation.lock('landscape')`；系统不支持时，按窗口尺寸旋转并居中横向布局。宽窗口不旋转，窗口尺寸改变后实时适配。受限制的浏览器保留系统地址栏。
- 退出按钮、Escape、浏览器退出系统全屏、手机/浏览器返回均恢复原布局；返回优先关确认弹窗，其次退出全屏，再次返回才进入离开确认。卸载时释放事件监听、方向锁与本次全屏；晚返回的旧请求不得关闭新会话。
- 原生安全区保留左右和底部边距，横屏确认弹窗跟随可视方向。全屏切换前后保留选牌和个人 `revision`。
- `test/spider_fullscreen.test.mjs` 验证浏览器全屏、缺少 API 的回退、异步取消、失败与晚返回清理。
