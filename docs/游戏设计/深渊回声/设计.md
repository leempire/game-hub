# 深渊回声

水下打捞队在沉没回收站打捞信标。深青色海底铺装、沉箱、海藻和锈金色平台标记提供环境识别。潜水员用铜色气瓶和青色头盔灯区分于敌人。漂囊有圆形囊体和尾须，裂鳍鳗狭长，锈甲蟹有双螯，断缆守卫沿用甲壳轮廓并放大体型、加首领血条。经验信标为浅蓝色菱形。

[浏览器美术原型](../../design/深渊回声/index.html) 可从本地打开。场景、角色、敌人、信标、武器图标和攻击特效均由 Canvas 代码绘制。原型提供 75 秒单人试潜，55 秒出现断缆守卫。**原型只用于看美术方向，玩法与数值以本文和 `增强调研.md` 为准。**

## 与《吸血鬼幸存者》的对齐原则

武器、被动、进化、经验曲线**按《吸血鬼幸存者》基础 12 把武器逐项对齐**，只换海下打捞的皮肤与名字。完整的逐级数值表、来源链接与「采纳 / 不采纳」见
[`增强调研.md`](增强调研.md)。

明确不照搬的部分：

- **联机槽位不按 VS 的 4/3/2 削减**：本作每人固定 6 武器 + 6 被动。VS 四人联机每人只有 2 把，正是本作旧版「最多两把」的来源；用户明确要求加多。
- **不做 Arcana、PowerUp 永久成长、角色差异、Limit Break、DLC 武器**。
- **不做 Reroll / Skip / Banish**：升级候选仍由服务端生成，6 秒超时自动选第一项。
- **不做金币经济**：Greed / Curse / Tiragisú 三个被动暂不进入候选池；宝箱固定给一次升级或进化，不做 1/3/5 档与 Luck 抽档。
- **局时长不固定 30 分钟**：默认 12 分钟，房主可在房规里选 12 / 20 / 30 分钟；经验节奏另有标准 / 快速 / 慢速三档。

## 对局结构

1–4 人在同一张 1440 × 1000 地图上推进。全队共享信标经验，达到门槛时战斗暂停，**每个还站着的玩家各自从 3 个候选里选 1 项**；Luck 足够高时有概率出现第 4 个候选。超过 6 秒未选自动采用第一项。

- 默认 12 分钟。精英在 1/3、2/3 时长出现，断缆守卫在 11/12 时长出现；击败守卫并活到时长结束才算回收成功。
- 房规「对局时长」可选 12 / 20 / 30 分钟，所有时间点按比例缩放。
- 房规「经验节奏」可选标准 / 快速 / 慢速（升级门槛 ×1 / ×0.8 / ×1.2）。
- 开局人数为 1/2/3/4 时，首测怪量和经验门槛倍率为 1/1.45/1.90/2.35，精英及首领血量倍率为 1/1.60/2.20/2.80。普通怪生命值保持同一基准。经验门槛沿用旧版的人数倍率，作为「每人多拿一份升级」的补偿。
- 靠近倒地队友连续 2 秒可以救起，恢复 35 HP，倒地超过 15 秒转为观战。全队无人站立时结束。

## 首轮实战平衡（与 VS 数值对齐后的必要调整）

旧版敌人血条是按「0.6 秒冷却、12 点伤害」的铆钉发射器定的；换成语义与数值都对齐 VS 的
Magic Wand（1.2 秒、10 点伤害）后，如果敌人血量不动，开场就会出现「两枪一只、怪潮越积越多」。
因此这一版同步下调了敌人侧参数：

| 参数 | 旧值 | 现值 |
|---|---:|---:|
| 漂囊 / 裂鳍鳗 / 锈甲蟹 血量 | 18 / 22 / 34 | 10 / 15 / 22 |
| 裂鳍鳗速度 | 115 | 105 |
| 接触伤害（普通 / 首领） | 10 / 20 | 6 / 12 |
| 受击无敌 | 0.8 秒 | 1.0 秒（对齐 VS 的 i-frame） |
| 刷怪速率（四阶段） | 1.10 / 1.95 / 3.35 / 4.5 每秒 | 0.85 / 1.3 / 2.0 / 2.7 每秒 |
| 首领阶段刷怪 | 3.0 每秒 | 1.9 每秒 |
| 同屏敌人上限 | min(190, 82 + 人数×27) | min(160, 50 + 人数×20) |

首轮自动模拟（会优先把一把武器顶到 8 级、捡宝箱、避开墙角的简易 AI）在 1–2 人局稳定通关，
3 人局多数种子通关，4 人局首测通关；等级落在 17–18。**真人实战与 Android 真机帧率仍需验收**，
尤其要观察：
- 12 分钟局里 6 武器 + 6 被动是否真的能成型（目前模拟里多数人只填满 2–4 把武器）；
- 宝箱是否被玩家主动拾取（进化是主要的中期跃升点）；
- 4 人队是否因为每人 6+6 而过于轻松。

## 经验与升级

VS 的三段经验曲线（单级）：

| 等级段 | 升级所需 XP |
|---|---|
| 2–19 | `10N − 15` |
| 20 | `185 + 600 = 785` |
| 21–39 | `13N − 75` |
| 40 | `445 + 2400 = 2845` |
| 41+ | `16N − 195` |

累计点：L20 = 2405、L40 = 11235、L41 = 11696。20 级与 40 级额外获得 +100% Growth，直到下一级。

本作实际门槛 = `ceil(单级 XP × 人数倍率 × 经验节奏倍率)`。

候选池规则：

- 已拥有且未满级的武器 / 被动可以升级。
- 武器槽未满时，未拥有的基础武器可以出现；被动槽未满时，未拥有的被动可以出现。
- 满级物品不再出现；已进化武器不出现。
- 先保证一个「已有物品升级」和一个「新物品」候选（各自可选时才加），再随机补足到 3 个；Luck 决定是否追加第 4 个。
- 池子不足时用「紧急补片 / 打捞锈币 / 短暂休整」补位。
- 宝箱不属于升级候选，它直接给一次升级或进化。

## 宝箱

- 两次精英与断缆守卫死亡时各掉一个宝箱；玩家走到 36 px 内自动打开，不被磁吸。
- 打开时**每个还站着的玩家各获得一次奖励**：优先按「满级基础武器 + 对应被动」进化；没有可进化的就随机升级一个未满级的武器 / 被动；全都满级则回血。
- 宝箱事件显示在战场顶部 3 秒，文案形如「潜水员甲：铆钉发射器 进化为 圣铆炮」。

## 属性

玩家属性由被动实时换算，快照里逐人下发：

| 属性 | 基准 | 来源 |
|---|---:|---|
| 伤害 Might | 100% | 浓缩燃素 |
| 范围 Area | 100% | 扩散声呐 |
| 冷却 Cooldown | 100% | 循环泵 |
| 持续 Duration | 100% | 延时引信 |
| 弹速 Speed | 100% | 流体加速器 |
| 数量 Amount | 0 | 分流阀 |
| 移速 Move Speed | 100% | 推进鳍 |
| 磁吸 Magnet | 1.0× | 信标磁锚 |
| 幸运 Luck | 100% | 幸运锈币 |
| 成长 Growth | 100% | 打捞执照 |
| 护甲 Armor | 0 | 抗压壳 |
| 回复 Recovery | 0/s | 自愈膜 |

伤害 = 武器基础伤害 × Might；范围、冷却、持续、弹速按同名属性乘算；数量 = 武器基础数量 + Amount。幸运同时提高暴击率与第 4 候选概率。

## 联机与实现约定

- 服务端固定步进 20 Hz，10 Hz 下发快照。客户端只预测本地位置并插值绘制远端移动；每 5 秒保存一份房间状态供服务重启恢复。
- 快照除玩家 / 敌人 / 信标 / 区域技能外，还包含飞行道具、环绕浮标、光环、宝箱和最近的宝箱事件；客户端不自己推演规律。
- 落盘和弱网发送沿用 GameHub 房间基础设施。`gs` 里的集合（命中记录、已刷事件）由 `persistence.py` 的编码器处理。
- 动态角色、敌人和攻击采用 SVG，适配桌面键盘和手机触摸。

## 已知近似（与 VS 不完全逐帧一致）

- **Soul Eater 回血**：VS 的精确回血机制依赖小爱心与已治疗量加伤；本作简化为「每次光环命中回少量生命，单次最多 3 HP」。
- **Armor 反伤**：只做了「受到伤害 -1/级」，没有做 VS 的 +10%/级反伤。
- **Garlic 的抗性削弱**：VS 每次命中会叠击退/冻结抗性削减；本作没有冻结与抗性系统，只保留伤害与范围。
- **命中延迟 / 池上限**：VS 的 Pool Limit、Hitbox Delay 只实现到行为层面（环绕 1.7 秒、水域 0.5 秒），没有做全量池上限。
- **暴击**：VS 的暴击多数要靠 Arcana 解锁；本作把武器词条上标注的暴击率直接启用。
- **Pentagram / Gorgeous Moon**：只做清屏、掉落保留（华月）与经验回收；没有做月束逐帧生成、逐帧真空吸与特殊敌人豁免。
- **NO FUTURE**：VS 的反伤爆炸简化为「反弹时的范围爆炸」。
- **宝箱档次**：只做固定 1 次奖励，没有 1/3/5 档、Luck 抽档与金币。
- **联机升级节奏**：VS 联机轮流选，本作每个存活玩家同时选（共享经验）。
- **经验门槛人数倍率**：VS 不按人数抬门槛；本作保留旧版 1/1.45/1.90/2.35，避免 4 人队升级过快。
