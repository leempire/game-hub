# 斗地主玩法与牌桌参考

调研时间 2026-11-25。中文资料来自竞技世界、腾讯和国家体育总局，英文资料来自运营方及公开研究。下文的首版建议作为默认「经典」档，房主可修改的选项见 [房间玩法设置](设计.md#房间玩法设置)。

## 一、三人经典玩法

- **发牌与阵营**。一副 54 张牌，含大小王。每人 17 张，留 3 张暗底牌。叫分结束后，地主拿走底牌，以 20 张手牌先出。两名农民各持 17 张，组成同一阵营。地主先出光则地主胜，任一农民先出光则两名农民同时获胜。JJ 规则和 kawu 均向全桌公开已确定归属的 3 张底牌。 [JJ 斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml) · [kawu 规则](https://kawu.com/doudizhu/rules) · [DouZero 论文附录 A.1](https://proceedings.mlr.press/v139/zha21a/zha21a-supp.pdf)
- **叫分**。玩家按座位轮流选择不叫或报出更高的分数，可报 1、2、3 分。叫到 3 分立即确定地主，否则一轮后最高叫分者当地主。JJ 产品页采用抽到标记牌者先叫、全员不叫重发，历史帮助页采用随机先叫、全员不叫则首叫者按 1 分当地主。kawu 采用随机先叫，全员不叫重发后由下一座位先叫。 [JJ 产品介绍](https://www.jj.cn/djddz/) · [JJ 斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml) · [kawu 规则](https://kawu.com/doudizhu/rules)
- **出牌与牌权**。领出时可打任意合法牌型。跟牌可打更大的同型同张数牌，或选择不出，即使手里有能压的牌也可不出。连续两家不出后，最后成功出牌的玩家重新领出。炸弹可压普通牌型，四张同点的炸弹之间按点数比较，双王组成王炸，可压任何牌。普通牌按 `3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王` 比较，花色只用于辨认实体牌。 [JJ 斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml) · [BluffKing 入门规则](https://bluffking.ai/en/blog/dou-dizhu-beginners-guide/) · [kawu 规则](https://kawu.com/doudizhu/rules)
- **计分**。乘法版以地主叫分为底分，每次实际打出的炸弹或王炸翻倍。地主赢且两名农民从未出牌是春天，农民赢且地主只出过第一手是反春，两者都再翻一倍。每个农民与地主独立结算相同分值，地主分值为单个农民的两倍，三人本局分数之和为零。JJ 部分比赛用加法控制炸弹的计分影响，QOJ 采用倍数从 1 起逐次加 1。BluffKing 的筹码场另有最高 16 倍及持有量限制。 [kawu 中文规则](https://kawu.com/zh/doudizhu) · [play.cards 计分规则](https://play.cards/rules/landlord#scoring) · [JJ 斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml) · [QOJ 规则](https://qoj.ac/games/doudizhu) · [BluffKing 结算说明](https://bluffking.ai/en/product/ddz/)

## 二、牌型与争议规则

下表把不同带牌数量拆为独立牌型，共 14 类。连续牌型的主体只用 3 至 A，比较最高主体点数。带牌的三张、飞机、四张分别以其主体比较。普通牌型须同类同张数才可互压，例如六张顺子压不了五张顺子。 [JJ 斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml) · [BluffKing 牌型表](https://bluffking.ai/en/blog/dou-dizhu-beginners-guide/) · [DouZero 论文附录表 3](https://proceedings.mlr.press/v139/zha21a/zha21a-supp.pdf)

| 牌型 | 张数与最低构成 | 示例 |
| --- | --- | --- |
| 单张 | 1 张 | `A` |
| 对子 | 2 张同点 | `77` |
| 三张 | 3 张同点 | `888` |
| 三带一 | 3 张同点带 1 张单牌 | `888 + 4` |
| 三带一对 | 3 张同点带 1 对 | `888 + 44` |
| 顺子 | 至少 5 个连续点数，每点 1 张 | `34567` |
| 连对 | 至少 3 个连续点数，每点 2 张 | `334455` |
| 飞机 | 至少 2 个连续点数，每点 3 张 | `333444` |
| 飞机带单 | N 组三张连续牌，每组带 1 张，共 `4 × N` 张 | `333444 + 79` |
| 飞机带对 | N 组三张连续牌，每组带 1 对，共 `5 × N` 张 | `333444 + 7799` |
| 四带两单 | 4 张同点带 2 张单牌，共 6 张 | `6666 + 39` |
| 四带两对 | 4 张同点带 2 对，共 8 张 | `6666 + 3399` |
| 炸弹 | 4 张同点 | `QQQQ` |
| 王炸 | 小王和大王 | `小王 大王` |

| 分歧 | 来源写法 | GameHub 草案 |
| --- | --- | --- |
| 飞机单翼能否拆对 | BluffKing 允许每个翼牌点数最多 2 张。play.cards 提供重复点数开关，kawu 要求单翼异点。 | `333444 + 77` 合法。每个翼牌点数至多 2 张，`333444555 + 777` 不能作为飞机带单。`333444555666` 按四组三张的裸飞机识别。 [BluffKing 牌型表](https://bluffking.ai/en/blog/dou-dizhu-beginners-guide/) · [play.cards 牌型设置](https://play.cards/rules/landlord) · [kawu 规则](https://kawu.com/doudizhu/rules) |
| 四带两单能否带一对 | BluffKing、QOJ 允许两张同点。kawu 只接受两张异点。 | `6666 + 77` 按四带两单识别。这样与飞机单翼允许拆对的规则一致。 [BluffKing 规则](https://bluffking.ai/en/product/ddz/) · [QOJ 规则](https://qoj.ac/games/doudizhu) · [kawu 规则](https://kawu.com/doudizhu/rules) |
| 翅膀与主体同点、两对或两个王 | BluffKing 明确飞机翼牌与主体异点、对翼和四带两对分别要求各对异点。kawu 禁止大小王同时作带牌。英文实体套装说明允许一张 2 或单王作为单翼，允许对 2 作为对翼。 | 所有带牌均须与主体异点。飞机单翼、四带两单可带 2 或单张王，禁止同时带大小王。飞机带对、四带两对的每对点数异于其余对子，可带对 2。`333444 + 3K`、`6666 + 7777` 与 `6666 + 小王 大王` 均非法。 [BluffKing 规则](https://bluffking.ai/en/product/ddz/) · [kawu 中文规则](https://kawu.com/zh/doudizhu) · [实体纸牌套装说明](https://jumbograzure.lhscdn.com/Uploads/290765/ff57_1144519-1333-rules.pdf) |

## 三、GameHub 首版建议（草案）

- **开局采用一轮 1／2／3 分竞价**。首副由随机座位先叫。三人都不叫时，用同一房间局重新洗牌并换下一座位先叫，上一副不计胜负或战绩。地主确定前，三张底牌仅存在服务端，确定后全桌可见。该选择保留玩家见牌后放弃地主的意义，也让重发的首叫机会轮转。 [JJ 产品介绍](https://www.jj.cn/djddz/) · [kawu 规则](https://kawu.com/doudizhu/rules)
- **牌型采用上表的 14 类**。默认允许拆对作单翼与四带两单。「严格带牌」采用 kawu 的单张带牌点数各异规则。两档都按选中的牌识别牌型，由服务端使用本局房规判牌和提供出牌提示。 [BluffKing 牌型表](https://bluffking.ai/en/blog/dou-dizhu-beginners-guide/) · [kawu 规则](https://kawu.com/doudizhu/rules) · [GameHub 游戏设计规范](../README.md)
- **正常打完按零和积分结算**。基数取 1，不另设倍数封顶。令 `B` 为本局实际打出的炸弹和王炸次数，`S` 为是否满足一次春天或反春（0 或 1），每名农民与地主间结算 `叫分 × 2^(B+S)`。四带两单、四带两对按普通牌型计算，出过即使被压的炸弹也计入倍率。例子是地主叫 2 分，一次炸弹且春天，按地主、农民、农民顺序结算 `+16、−8、−8`。结算显示底分、炸弹／王炸和春天的各项来源。 [kawu 规则](https://kawu.com/doudizhu/rules) · [play.cards 计分规则](https://play.cards/rules/landlord#scoring) · [JJ 斗地主规则](https://www.jj.cn/news/320/20110920103700018196.shtml)
- **首版以三人好友桌积分为范围**。叫／抢地主会增加一套竞价流程，癞子会改变牌型识别和炸弹规则。四人版和赛制各自改变发牌、胜负结算或组桌方式。这些变体适合在三人局跑通后按实际需求评估。 [play.cards 竞价设置](https://play.cards/rules/landlord) · [JJ 产品玩法列表](https://www.jj.cn/djddz/) · [JJ 四人斗地主规则](https://www.jj.cn/news/320/20110926162600018457.shtml)

### 竞技复式与四人双副

国家体育总局发布说明中的复式，是让同一方位拿到相同手牌的选手比较成绩，以减弱发牌运气对排名的影响。南宁全国总决赛报道中的团体赛也使用一副牌，同一副牌在开室与闭室复用。JJ 的四人双副则是在同一桌混用两副牌，共 108 张，四人各发 25 张、留 8 张底牌，一地主对三农民，炸弹与王炸都有另行规定。 [国家体育总局规则发布说明](https://www.sport.gov.cn/n20001280/n20067662/n20067613/c22917445/content.html) · [全国总决赛报道](https://www.sport.gov.cn/n315/n20066836/c20651267/content.html) · [JJ 四人斗地主规则](https://www.jj.cn/news/320/20110926162600018457.shtml)

## 四、牌桌交互参考

- **区分选牌和出牌**。kawu 支持点按抬牌和拖动多选。提示可轮换合法组合，选牌无效时禁用出牌并说明原因。GameHub 可先把单击／点按作为完整选牌路径，验收时用 20 张叠放手牌找出选错牌的窄屏宽度，再决定是否加拖选。网页拖动交互仍需有单指无拖动操作。 [kawu 交互说明](https://kawu.com/doudizhu/rules) · [W3C 拖动操作标准](https://www.w3.org/TR/WCAG22/#dragging-movements) · [GameHub 移动端体验设计方法论](../../移动端体验设计方法论.md)
- **保留有决策价值的桌面信息**。BluffKing 的农民配合示例依赖上手出牌人、上一手牌和各方余牌数。JJ 判罚条例的微型记牌器可查看上一手牌和底牌标记，kawu 提醒对手剩一张或两张。GameHub 可优先展示地主／农民、当前出牌人、上手牌、底牌和余牌，倍数变化用可回看的文字反馈。 [BluffKing 农民配合示例](https://bluffking.ai/en/blog/dou-dizhu-beginners-guide/#farmer-teamwork) · [JJ 斗地主判罚条例](https://cl.my.jj.cn/html/appeal/appeal_game/index.html) · [kawu 交互说明](https://kawu.com/doudizhu/rules)
- **桌面装饰与牌面可独立取舍**。腾讯开发者介绍和波克公司的产品披露采用场景与角色强化气氛，波克示例同时展示电脑与手机版本。GameHub 可沿用主题色板，手牌点数、出牌者及阶段动作应在视觉上优先于背景和人物装饰。 [腾讯《欢乐斗地主》官网](https://hlddz.qq.com/) · [腾讯产品介绍](https://www.taptap.cn/app/6517/all-info) · [波克公司招股说明书「波克斗地主」](https://static.cninfo.com.cn/finalpage/2015-11-13/1201774989.PDF) · [GameHub 游戏设计规范](../README.md)
