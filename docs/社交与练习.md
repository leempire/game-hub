# 练习、局内快捷语与只读观战

## 练习

深空休眠、军棋、海战棋、UNO 的新手入口可调用 `POST /api/practice/{game}`，登录态与普通API相同。
返回 `{code, room, reused}`：每款游戏创建或复用本人的私人普通人机房，之后走正常房间页与房主开始流程。
`room.practice=true`，真人只有本人，默认一名普通难度人机；已经出局但队友还在继续的旧练习不复用。

练习房不进公共房间列表，其他用户即使知道房间号或内部密码也不能加入。练习仍可重连、准备、返回大厅续开；战绩记录带 `practice=1`，历史列表、统计、榜单都排除，不影响胜率和连胜。私人练习不开放观战。

## 局内快捷语

仅UNO和深空休眠、正在对局的真人玩家可用。`room.quick_phrases` 下发 `{id,text}[]`，客户端只显示这些选项。

`POST /api/rooms/{code}/quick-chat`，请求体仅 `{id: string}`。服务端从白名单取文本与真实用户昵称，拒绝自由文本或额外字段；同一房间同一用户间隔至少2秒，过快返回429。

广播消息：`{type:'quick_chat', id, user_id, name, text}`。真人玩家及独立观战连接均收到；观战者与非成员不能发送。
不落盘、没有历史聊天，不引入自由聊天/语音。非法选择400，非在局真人403，未知房间404。

## 观战授权与协议

仅UNO和深空休眠，默认关闭；房主在等待大厅开启 `room_setting {key:'allow_spectators',value:true}`。
观战不占座，不增加在线玩家，不改变任何人的准备、断线保座或战绩；满房及进行中的房间均可观战。

1. 登录后 `POST /api/rooms/{code}/watch`，请求 `{password?:string}`。密码房的非成员需密码；已授权成员可直接访问。
2. 返回 `{grant, ws_path, game}`；用 `/ws/watch/{code}?token=<JWT>&grant=<随机许可>` 连接独立WS。
3. 初始 `watch_sync`，之后只在公开状态变化时发送 `watch_state`（每500ms采样）。两者都是 `{type,read_only:true,room,game}`，尚未开局时 `game:null`。
4. 只接受 `{type:'ping'}` 并回复 `pong`。任何出牌、建造、认输等消息一律返回只读错误，绝不进入普通房间动作处理器。

许可绑定用户、房间实例及权限代数，可以重连复用；房间关闭或房主关观战会断开，快速关闭再打开也不能恢复旧许可，须重新POST获取。服务端重启后重新获取许可。
未登录/登录失效关闭码4001，许可失效/观战关闭4003，连接发送失败4000。授权HTTP失败403，未知房间404。

UNO采用公开字段白名单：弃牌顶、当前色、方向、回合、罚牌张数、各座位手牌张数、公开UNO标记、组队及结果、累计赛分。
**不包含**手牌、抽牌堆、可出/抢出列表、个人身份字段和+4质疑私有证据。新增引擎字段默认不进入观战载荷。
深空休眠复用合作游戏公开布局、建筑、玩家与静默体状态，去掉 `your_uid/your_seat`。观战不驱动游戏tick，只有真实玩家连接参与房间生命周期。

独立观战发送串行化并设2秒上限；连接结束取消采样与接收任务，不留后台任务。封号及改密通过统一kick_user立即撤销许可、关闭观战；JWT定期复核作为兜底。

## 接线与验证

- `practice.py`：私人练习创建与复用；`quick_phrases.py`：纯短语目录；`quick_chat.py`：授权与限流；`spectating.py`：许可、公开视图、独立WS。
- `routers/game_social.py`：四个路由，由 `main.py` 挂载。
- 房间层需：练习入房守卫、公共列表过滤、`room_to_dict.quick_phrases`。这些与普通房间连接保持分离。
- `server/test/test_game_social.py`：真实HTTP/WS覆盖练习权限与统计排除、快捷语限流与伪造字段、满员观战、UNO隐私与未来字段白名单、只读攻击、密码/用户绑定、权限撤销、重连不改席位、公开实时更新及发送上限。

参考：[FastAPI WebSocket生命周期](https://fastapi.tiangolo.com/advanced/websockets/)、[OWASP WebSocket消息级授权与输入校验](https://cheatsheetseries.owasp.org/cheatsheets/WebSocket_Security_Cheat_Sheet.html)、[PokerTH观战隐藏底牌的产品实践](https://webclient.pokerth.net/faq?lang=zh)。采用独立只读权限和公开字段白名单；不复用真人座位、客户端隐藏手牌或自由文本消息。

## 客户端引导、练习与快捷语

四款复杂游戏（深空休眠、军棋、海战棋、UNO）等待大厅挂载 `GameIntro`，每款至多三步，可跳过或随时重开。首次完成/跳过以账户和游戏分别保存在本机；切入对局后指引不覆盖牌桌。练习按钮创建或复用私人房并切换到该房间，保留正常准备和开始流程，显式提示不计历史、统计和排行榜；请求失败保留入口和错误提示，并发点击只发一次请求。

UNO、深空对局挂载 `QuickChatControls`，只渲染房间提供的短语目录，不提供自由输入。点击后按固定ID调用HTTP接口；来自本人、队友和观战连接的广播由各自WS接收，牌桌显示最新一条。客户端成功发送后冷却2秒，服务端仍独立校验权限和限流；断线、出局、结束后不可发送，失败保留选择面板供重试。

`test/social_controls.test.mjs` 验证三步与跳过记忆、练习并发去重与失败、快捷语固定ID/并发/冷却、断线保护及实时消息订阅清理。`test/e2e_social.py` 使用隔离后台和真实浏览器检验完整入口、传播、观战及练习统计排除。
